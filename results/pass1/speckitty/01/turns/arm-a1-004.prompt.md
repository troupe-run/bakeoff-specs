A. The contract requires byte-surgical write-back: after a successful `set`, the only bytes that differ in any file are the ones the `set` section requires to change. Users hand-edit these files and review the diffs, so byte-surgical write-back matters more than speed. You may pick any technique that guarantees this. A round-trip dump that normalises indentation, quoting, flow spacing, folded scalars or comment spacing would break that rule.
