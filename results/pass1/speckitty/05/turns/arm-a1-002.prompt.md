With nested includes, that is the file holding the reference to the include that the key's deepest existing ancestor comes from. In your example that is `agents/coder.yaml`, which gets the override `model: {$ref: file:models/base.yaml, temperature: 0.3}` written in block form. Follow the contract's definition.
