# bakeoff-specs Plan 2 — the runner — Implementation Plan (DRAFT)

> **Status: DRAFT for owner review.** Written 2026-09-29 while the owner was asleep. Nothing in it has been
> implemented, no candidate has been run, and GitHub has not been touched. Every point where the design is
> silent is listed under **Owner decisions needed**, with the default this draft assumes.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A deterministic, scriptable runner that takes each arm through setup, the seven-step evolution
(pass 1 and pass 2), the product-owner loop and the owner's gates; that runs the hidden tests and quality
tools against every step's result; and that records every piece of evidence design §7 asks for, applying the
§9 stop rules. The LLM sessions (the arm, the product-owner agent, the step-2 "teammate") are the only
non-deterministic parts.

**Architecture:** A Python package `runner/` in this repo, driven from the owner's terminal
(`uv run python -m runner …`). Every Claude session runs as `claude -p` inside a throwaway container built
from spike B's stage: pinned Claude Code 2.1.281, read-only root, no capabilities, `--init`, an
`--internal` network whose only way out is an allowlisting CONNECT proxy, and the owner's OAuth token handed
over stdin → fd 3 (never env, argv, disk or `docker inspect`). Each arm has a persistent per-pass home
directory (its `CLAUDE_CONFIG_DIR`, plugins, caches) and a work directory holding its repo; both are mounted
into every turn's container, so sessions continue with `--resume`. After each step the runner exports the
arm's committed `main` into a scratch copy and runs `pytest tests/hidden` **inside a separate tester
container** (the harness mounted read-only only there), which resolves every `PLAN-2 NOTE` from Plan 1 by
putting pytest, the arm's CLI, the HTTP fixture and the theatre directories in one process tree, one user
and one filesystem. Arm behaviour (install, egress, entry commands, tracker, checks) is data in
`runner/config/arms/<arm>.toml`; the runner code is arm-agnostic.

**Tech Stack:** Python 3.12 stdlib (`asyncio`, `subprocess`, `tomllib`, `json`, `dataclasses`), pytest
(runner unit tests + `docker`-marked integration tests), Docker 29 (Docker Desktop, macOS), tinyproxy
(egress), Claude Code 2.1.281 native binary, uv 0.12.19, gh 2.101.0, mypy / ruff / mutmut pinned in the
tester image.

**Spec:** [`docs/design.md`](../../design.md) (approved 2026-09-28). Inputs: Plan 1
[`2026-09-28-measuring-instrument.md`](2026-09-28-measuring-instrument.md) and its
[ledger](2026-09-28-measuring-instrument.ledger.md) (every `PLAN-2 NOTE` is a requirement here),
[`research/CANDIDATES.md`](../../../research/CANDIDATES.md), `../spike-claude-docker/FINDINGS.md`.

**Scope:** Plan 2 of 3. Scoring and judging (anonymisation, LLM judges, weights) are Plan 3. This plan
produces the evidence Plan 3 scores; where it measures something only Plan 3 interprets (e.g. hand-edit
detection), it records raw facts, not scores.

## Global Constraints

- **Pins (design §2, §11):** Claude Code `2.1.281`; model `claude-opus-5-5`, passed as `--model` on every
  session (arm, PO, teammate); tool versions per OD9. Every pin is recorded in `runner/config/pins.toml`, the
  single source of truth for them, and copied into every `run.json`. No upgrade mid-bake-off: the runner
  refuses to start a step if an image digest differs from the one recorded at the arm's setup.
- **Model pin is verified, not assumed (design §11):** every `assistant` line in every transcript file
  (including `subagents/`), every `system/init` event and every `result.modelUsage` key is checked against
  `accepted_models`. Anything else is a `model-pin` harness fault, and the step is re-run from its
  snapshot.
- **Isolation (design §6):** each arm has its own `CLAUDE_CONFIG_DIR` (inside its own home directory);
  `CLAUDE_CODE_DISABLE_AUTO_MEMORY=1`, `DISABLE_AUTOUPDATER=1`, `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1`,
  `OPENSPEC_TELEMETRY=0` in every arm container; `--strict-mcp-config` with no MCP servers; the owner's
  `~/.claude` is never mounted.
- **Container stage (design §11, spike B):** `--rm --init --read-only --cap-drop ALL --security-opt
  no-new-privileges --user 1000:1000 --pids-limit 2048 --cpus 4 --memory 8g`, a per-arm `--internal`
  network plus an allowlisting proxy, `--label bakeoff.run=<pass>/<arm>`, and a supervisor-chosen `--name`.
  Cancellation is `docker stop -t 30 <name>`, then `docker rm -f <name>`; killing the local `docker` CLI is
  never enough. A startup sweep removes labelled leftovers.
- **Credential (spike B, OD16):** never in env, argv, a file inside the container, a log or `docker
  inspect`. Stdin line 1 → wrapper → fd 3 → `CLAUDE_CODE_OAUTH_TOKEN_FILE_DESCRIPTOR=3`. A runner unit test
  asserts that the token string appears in no argv and no env built by the runner.
- **Outcome is derived, not trusted (spike B Q8):** `result.is_error` is checked (it can be `true` with
  subtype `success`); the absence of a `result` event means the turn was cancelled or crashed;
  `api_retry` with `authentication_failed` → abort the turn at once (harness fault `infra-auth`);
  `CLAUDE_CODE_MAX_RETRIES=4`.
- **Hidden tests never enter an arm repo or an arm session container (design §6);** `tests/hidden` is
  mounted read-only only into the tester container, which has `--network none`.
- **The PO brief the arm experiences is recorded:** every step's `run.json` carries the SHA-256 of
  `scenario/po-brief.md`, `scenario/contract.md` and the step brief as used.
- **One thing at a time (design §5, Plan 1 idle-machine note):** the runner holds a lock file
  (`state/runner.lock`); nothing runs concurrently with a hidden-test run; preflight refuses to test if any
  other `bakeoff.*` container is running or the 1-minute load average exceeds `0.5 × cpu_count`
  (configurable).
- **GitHub writes are owner-confirmed, one at a time;** repo creation is never done by the runner.
- **The runner is deterministic:** all choices (order, templates, classifications applied, retries) are
  derived from config and recorded inputs; the only non-determinism is inside LLM sessions, and each
  session's full input and output is saved.

## Review Focus

1. **Credential leakage.** The token must be unreachable via argv, env, `docker inspect`, logs, results or
   transcripts. Tasks 5 and 6 have tests for this; reviewers should also grep `results/` of the dry run for
   the dummy token.
2. **Unequal treatment of arms.** Anything that differs per arm must be data in `arms/<arm>.toml` and must
   follow from that tool's own docs (CANDIDATES.md). Harness-authored text (entry prefixes, PO protocol,
   fixed nudges) must be identical across arms or justified in the toml. Reviewers: diff the seven toml
   files.
3. **Leaks of hidden information into arm sessions.** The PO must not see the tests, and nothing in an arm's
   mounts may contain harness paths. Pass 2 must start with no pass-1 state (OD20).
4. **Harness faults misclassified as arm faults (and vice versa).** The model pin, API/auth failures, PO
   protocol failures and flaky hidden tests must never count against an arm (Task 18's table).
5. **PLAN-2 NOTEs.** Each one is resolved by construction in Task 15 and exercised by the dry run (Task 20).
   Reviewers should tick them off against the resolution table there.
6. **Tests whose names overclaim** (owner's rule). A runner test named "never leaks the token" must actually
   search every argv/env the runner builds.

```python
@dataclass(frozen=True)
class Plugin:
    marketplace: str      # e.g. "obra/superpowers-marketplace" or "" for the default official one
    plugin: str           # e.g. "superpowers@claude-plugins-official"
    version: str          # pinned; verified by the checklist
    tag: str = ""         # git tag for the --plugin-dir fallback (OD9)

@dataclass(frozen=True)
class Arm:
    name: str
    tool: str
    version: str
    image: str
    tracker: str
    repo_name: str
    env: dict[str, str]
    egress_setup: list[str]
    egress_run: list[str]
    setup_shell: list[str]
    setup_agent: list[str]
    plugins: list[Plugin]
    entry: str
    bug_entry: str
    must_run: list[str]
    dry: bool = False

_ANCHORED = re.compile(r"^\^.+\$$")

def _check_hosts(patterns: list[str], where: str) -> list[str]:
    for p in patterns:
        if not _ANCHORED.match(p):
            raise ConfigError(f"{where}: host pattern {p!r} must be anchored (^…$), spike B Q3")
    return list(patterns)

def _only(d: dict, allowed: set[str], where: str) -> dict:
    extra = set(d) - allowed
    if extra:
        raise ConfigError(f"{where}: unknown key(s) {sorted(extra)}")
    return d

def load_pins() -> Pins:
    raw = tomllib.loads((CONFIG_DIR / "pins.toml").read_text())
    c, e = raw["claude"], raw["egress"]
    return Pins(
        claude_version=c["version"], model=c["model"], accepted_models=list(c["accepted_models"]),
        synthetic_models=list(c["synthetic_models"]), max_retries=int(c["max_retries"]),
        permission_mode=c["permission_mode"], disallowed_tools=list(c["disallowed_tools"]),
        images=dict(raw["images"]), limits=Limits(**raw["limits"]),
        egress_setup_common=_check_hosts(e["setup_common"], "pins.egress.setup_common"),
        egress_run_common=_check_hosts(e["run_common"], "pins.egress.run_common"),
        egress_po=_check_hosts(e["po"], "pins.egress.po"),
        egress_tester_prep=_check_hosts(e["tester_prep"], "pins.egress.tester_prep"),
    )

def load_arm(name: str) -> Arm:
    where = f"arms/{name}.toml"
    raw = _only(tomllib.loads((ARMS_DIR / f"{name}.toml").read_text()),
                {"name", "tool", "version", "image", "tracker", "repo_name", "env", "egress", "setup", "drive", "dry"},
                where)
    eg = _only(raw.get("egress", {}), {"setup", "run"}, where + " [egress]")
    su = _only(raw.get("setup", {}), {"shell", "agent", "plugins"}, where + " [setup]")
    dr = _only(raw.get("drive", {}), {"entry", "bug_entry", "must_run"}, where + " [drive]")
    if raw.get("tracker") not in ("github", "beads", "dry"):
        raise ConfigError(f"{where}: tracker must be github|beads|dry")
    if "{handoff}" not in dr.get("entry", "") or "{handoff}" not in dr.get("bug_entry", ""):
        raise ConfigError(f"{where}: entry and bug_entry must contain {{handoff}}")
    return Arm(
        name=raw["name"], tool=raw["tool"], version=raw["version"], image=raw["image"], tracker=raw["tracker"],
        repo_name=raw["repo_name"], env=dict(raw.get("env", {})),
        egress_setup=_check_hosts(eg.get("setup", []), where), egress_run=_check_hosts(eg.get("run", []), where),
        setup_shell=list(su.get("shell", [])), setup_agent=list(su.get("agent", [])),
        plugins=[Plugin(**p) for p in su.get("plugins", [])],
        entry=dr["entry"], bug_entry=dr["bug_entry"], must_run=list(dr.get("must_run", [])),
        dry=bool(raw.get("dry", False)),
    )

def all_arms() -> list[str]:
    return list(REAL_ARMS)
```

```python
# runner/images.py
from __future__ import annotations
import json, subprocess
from pathlib import Path
from runner import config

IMAGES = Path(__file__).resolve().parent / "images"
LOCK = config.CONFIG_DIR / "images.lock.json"
VERSION_PROBES = {"claude": ["claude", "--version"], "uv": ["uv", "--version"], "python3": ["python3", "--version"],
                  "node": ["node", "--version"], "gh": ["gh", "--version"], "git": ["git", "--version"]}

def _sh(*argv: str) -> str:
    return subprocess.run(argv, check=True, capture_output=True, text=True).stdout.strip()

def current_id(tag: str) -> str:
    return _sh("docker", "image", "inspect", "--format", "{{.Id}}", tag)

def _build(tag: str, context: Path, **args: str) -> None:
    argv = ["docker", "build", "-q", "-t", tag]
    for k, v in args.items():
        argv += ["--build-arg", f"{k}={v}"]
    subprocess.run([*argv, str(context)], check=True)

def _versions(tag: str, extra: dict[str, list[str]]) -> dict[str, str]:
    out = {}
    for name, cmd in {**VERSION_PROBES, **extra}.items():
        r = subprocess.run(["docker", "run", "--rm", "--network", "none", tag, *cmd], capture_output=True, text=True)
        out[name] = (r.stdout or r.stderr).strip().splitlines()[0] if (r.stdout or r.stderr) else f"exit {r.returncode}"
    return out

ARM_VERSION_PROBES = {
    "openspec": {"openspec": ["openspec", "--version"]},
    "speckit": {"specify": ["specify", "version"]},
    "speckitty": {"spec-kitty": ["spec-kitty", "--version"], "bd": ["bd", "version"]},
    "ccsdd": {"cc-sdd": ["npm", "ls", "-g", "cc-sdd"]},
}

def build_all(arms: list[str]) -> dict:
    pins = config.load_pins()
    im = pins.images
    _build(im["base"], IMAGES / "base", CLAUDE_VERSION=pins.claude_version, UV_VERSION=im["uv"],
           GH_VERSION=im["gh"], NODE_IMAGE=f"node:{im['node_major']}-bookworm-slim")
    _build(im["proxy"], IMAGES / "proxy")
    _build(im["tester"], IMAGES / "tester")
    lock = {"base": {"id": current_id(im["base"]), "versions": _versions(im["base"], {})},
            "proxy": {"id": current_id(im["proxy"])},
            "tester": {"id": current_id(im["tester"])},
            "node_base_digest": _sh("docker", "image", "inspect", "--format", "{{index .RepoDigests 0}}",
                                    f"node:{im['node_major']}-bookworm-slim"),
            "arms": {}}
    for name in arms:
        arm = config.load_arm(name)
        if (IMAGES / "arm" / name / "Dockerfile").exists():
            _build(arm.image, IMAGES / "arm" / name)
        lock["arms"][name] = {"image": arm.image, "id": current_id(arm.image),
                              "versions": _versions(arm.image, ARM_VERSION_PROBES.get(name, {}))}
    LOCK.write_text(json.dumps(lock, indent=2, sort_keys=True) + "\n")
    return lock

def lock() -> dict:
    return json.loads(LOCK.read_text())
```

**The egress model.** Four phases, each with its own proxy allowlist (anchored host regexes, spike B Q3). The
`--internal` network is what enforces it: no route out and no external DNS; the proxy is only the allow path
and the log.

| Phase | When | Allowlist | Why |
|---|---|---|---|
| Image build | once, `runner images build` | unrestricted (normal `docker build`) | OS packages, Claude binary, uv, Python, Node, gh, method CLIs; results pinned by the image lock |
| Setup | `runner setup <pass> <arm>` | `pins.egress.setup_common` + `arm.egress.setup` | plugin marketplaces (github.com), `npx`, `specify init` template download, `bd init`, the setup agent turns (Anthropic) |
| Run | every step session | `pins.egress.run_common` + `arm.egress.run` | Anthropic API; PyPI so the arm can `uv add` its own dependencies; `api.github.com` only for arms whose tracker is GitHub |
| Tester | hidden tests / quality | prep: PyPI only; run: `--network none` | `uv sync` of the arm's lockfile, then fully offline |
| PO / teammate | PO decisions, step-2 hand edit | Anthropic only | — |

Every proxy decision is saved as `egress.log` in the step's results. Refusals are listed in `summary.md` for
the owner. A refusal is not a fault by itself (the arm tried to reach a host); the owner may classify one as
a harness fault if the method's documented operation needed that host (Task 18).

```python
# runner/docker.py
"""docker argv builders (pure) and the few effectful calls. The argv is built only from declared inputs:
no env pass-through, no implicit mounts (spike B Q2)."""
from __future__ import annotations
import subprocess
from dataclasses import dataclass, field
from pathlib import Path
from runner.config import Limits

@dataclass(frozen=True)
class Mount:
    host: Path
    ctr: str
    ro: bool

@dataclass(frozen=True)
class RunSpec:
    name: str
    image: str
    label: str
    network: str                 # a network name, or "none"
    mounts: list[Mount]
    env: dict[str, str]
    workdir: str
    cmd: list[str]
    stdin: bool
    limits: Limits
    proxy: bool

def run_argv(s: RunSpec) -> list[str]:
    a = ["docker", "run", "--rm", "--init", "--name", s.name, "--label", s.label,
         "--read-only", "--tmpfs", "/tmp:rw,exec,nosuid,nodev,size=4g",
         "--user", "1000:1000", "--cap-drop", "ALL", "--security-opt", "no-new-privileges",
         "--pids-limit", str(s.limits.pids), "--cpus", s.limits.cpus, "--memory", s.limits.memory,
         "--network", s.network, "-w", s.workdir]
    if s.stdin:
        a.append("-i")
    env = dict(s.env)
    if s.proxy:
        env |= {"HTTPS_PROXY": "http://egress:3128", "HTTP_PROXY": "http://egress:3128",
                "NO_PROXY": "localhost,127.0.0.1"}
    for k in sorted(env):
        a += ["-e", f"{k}={env[k]}"]
    for m in s.mounts:
        a += ["-v", f"{m.host}:{m.ctr}:{'ro' if m.ro else 'rw'}"]
    return [*a, s.image, *s.cmd]

def stop_argv(name: str, grace: int = 30) -> list[str]:
    return ["docker", "stop", "-t", str(grace), name]

def rm_argv(name: str) -> list[str]:
    return ["docker", "rm", "-f", name]

def stop(name: str) -> None:
    """Graceful then hard; never relies on killing the local docker CLI (spike B Q5)."""
    subprocess.run(stop_argv(name), capture_output=True)
    subprocess.run(rm_argv(name), capture_output=True)

def sweep(label_prefix: str = "bakeoff.run") -> list[str]:
    ids = subprocess.run(["docker", "ps", "-aq", "--filter", f"label={label_prefix}"],
                         capture_output=True, text=True).stdout.split()
    for i in ids:
        subprocess.run(rm_argv(i), capture_output=True)
    return ids

def running(label_prefix: str = "bakeoff.run") -> list[str]:
    return subprocess.run(["docker", "ps", "-q", "--filter", f"label={label_prefix}"],
                          capture_output=True, text=True).stdout.split()
```

```python
# runner/egress.py
"""Per-arm, per-phase egress stage: an --internal network plus an allowlisting tinyproxy (spike B Q3)."""
from __future__ import annotations
import re, subprocess, tempfile
from pathlib import Path
from runner import config

_CONNECT = re.compile(r"CONNECT ([^:\s]+):\d+")
_REFUSED = re.compile(r'refused on filtered domain "([^"]+)"')

def allowlist_text(hosts: list[str]) -> str:
    return "".join(h + "\n" for h in hosts)

def decisions(log: str) -> list[tuple[str, str]]:
    out: list[tuple[str, str]] = []
    for line in log.splitlines():
        if m := _CONNECT.search(line):
            out.append((m.group(1), "allowed"))
        elif (m := _REFUSED.search(line)) and out and out[-1][0] == m.group(1):
            out[-1] = (m.group(1), "refused")
    return out

class Stage:
    def __init__(self, pass_: str, arm: str, phase: str, hosts: list[str], log_to: Path):
        self.net = f"bk-net-{pass_}-{arm}-{phase}"
        self.proxy = f"bk-proxy-{pass_}-{arm}-{phase}"
        self.label = f"bakeoff.run={pass_}/{arm}"
        self.hosts, self.log_to = hosts, log_to

    def __enter__(self) -> "Stage":
        self._allow = tempfile.NamedTemporaryFile("w", suffix=".txt", delete=False)
        self._allow.write(allowlist_text(self.hosts)); self._allow.close()
        Path(self._allow.name).chmod(0o644)
        subprocess.run(["docker", "network", "create", "--internal", "--label", self.label, self.net],
                       check=True, capture_output=True)
        subprocess.run(["docker", "run", "-d", "--name", self.proxy, "--label", self.label, "--network", "bridge",
                        "-v", f"{self._allow.name}:/etc/tinyproxy/allow.txt:ro",
                        config.load_pins().images["proxy"]], check=True, capture_output=True)
        subprocess.run(["docker", "network", "connect", "--alias", "egress", self.net, self.proxy],
                       check=True, capture_output=True)
        return self

    def __exit__(self, *exc) -> None:
        log = subprocess.run(["docker", "logs", self.proxy], capture_output=True, text=True)
        self.log_to.parent.mkdir(parents=True, exist_ok=True)
        with open(self.log_to, "a") as fh:
            fh.write(log.stdout + log.stderr)
        subprocess.run(["docker", "rm", "-f", self.proxy], capture_output=True)
        subprocess.run(["docker", "network", "rm", self.net], capture_output=True)
        Path(self._allow.name).unlink(missing_ok=True)
```

```python
# runner/credentials.py
"""The OAuth token lives only in this process's memory and on one container's stdin (spike B option a′)."""
from __future__ import annotations
import subprocess
from runner.config import Arm, Pins

class Credential:
    __slots__ = ("_t", "_dummy")
    def __init__(self, token: str, dummy: bool = False):
        self._t, self._dummy = token.strip(), dummy
    def payload(self) -> bytes:
        return (self._t + "\n").encode()
    def check_allowed(self, arm: Arm) -> None:
        if self._dummy and not arm.dry:
            raise PermissionError("the dummy credential may only drive dry-run arms")
    def __repr__(self) -> str:
        return "<credential>"
    __str__ = __repr__
    def __format__(self, spec: str) -> str:
        return "<credential>"

def from_keychain(service: str = "bakeoff-claude-oauth") -> Credential:
    r = subprocess.run(["security", "find-generic-password", "-s", service, "-w"], capture_output=True, text=True)
    if r.returncode != 0 or not r.stdout.strip():
        raise RuntimeError(f"no keychain item {service!r}; see checklists/README.md (owner one-time step)")
    return Credential(r.stdout)

def dummy() -> Credential:
    return Credential("dry-run-dummy-token", dummy=True)

def session_env(pins: Pins, arm: Arm, *, isolated: bool, tools: str = "", resume: str = "") -> dict[str, str]:
    m = pins.model
    env = {
        "BK_MODEL": m, "BK_PERMISSION_MODE": pins.permission_mode,
        "BK_DISALLOWED": ",".join(pins.disallowed_tools),
        "ANTHROPIC_DEFAULT_OPUS_MODEL": m, "ANTHROPIC_DEFAULT_SONNET_MODEL": m,
        "ANTHROPIC_DEFAULT_HAIKU_MODEL": m, "CLAUDE_CODE_SUBAGENT_MODEL": m,
        "CLAUDE_CODE_DISABLE_AUTO_MEMORY": "1", "DISABLE_AUTOUPDATER": "1",
        "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1", "CLAUDE_CODE_MAX_RETRIES": str(pins.max_retries),
        "CLAUDE_CONFIG_DIR": "/home/actor/.claude", "OPENSPEC_TELEMETRY": "0",
        **arm.env,
    }
    if isolated:
        env["BK_ISOLATED"] = "1"
    if tools:
        env["BK_TOOLS"] = tools
    if resume:
        env["BK_RESUME"] = resume
    return env
```

```python
import json, os, sys, time, uuid
from pathlib import Path

    return a[a.index(name) + 1] if name in a else default

    print(json.dumps(o), flush=True)

        print("2.1.281 (Claude Code)"); return 0
    prompt = arg("-p", "")

    directives = dict(l[5:].split("=", 1) if "=" in l else (l[5:], "1") for l in prompt.splitlines() if l.startswith("FAKE:"))
    emit(type="system", subtype="init", session_id=sid, model=directives.get("init_model", model),
         claude_code_version="2.1.281", tools=["Bash", "Read", "Edit", "Write", "Task"], cwd=os.getcwd())
    if "auth_fail" in directives:
        emit(type="system", subtype="api_retry", attempt=1, max_retries=4, error="authentication_failed")

    if "sleep" in directives:
        time.sleep(float(directives["sleep"]))
    text = directives.get("reply", "OK")
    # Transcript, where Claude Code keeps it: $CLAUDE_CONFIG_DIR/projects/<cwd slug>/<session>.jsonl

    emit(type="result", subtype="success", is_error="is_error" in directives, result=text, session_id=sid,
         total_cost_usd=0.0, usage={"input_tokens": 1, "output_tokens": 1},
         modelUsage={directives.get("model", model): {"inputTokens": 1, "outputTokens": 1}},
         token_seen=bool(token.strip()))
    return 0
```

```python
# runner/session.py
from __future__ import annotations
import asyncio, gzip, json, time
from dataclasses import dataclass, field
from pathlib import Path
from typing import Iterable, Literal
from runner import docker
from runner.credentials import Credential
from runner.docker import Mount, RunSpec
from runner.config import load_pins

Outcome = Literal["ok", "is_error", "no_result", "timeout", "auth_failed"]

@dataclass
class Parsed:
    session_id: str | None = None
    init: dict = field(default_factory=dict)
    result: dict | None = None
    retries: list[dict] = field(default_factory=list)
    auth_failed: bool = False

    @property
    def outcome(self) -> Outcome:
        if self.auth_failed:
            return "auth_failed"
        if self.result is None:
            return "no_result"
        return "is_error" if self.result.get("is_error") else "ok"
    @property
    def final_text(self) -> str:
        return (self.result or {}).get("result") or ""
    @property
    def cost_usd(self) -> float:
        return float((self.result or {}).get("total_cost_usd") or 0.0)

def feed(p: Parsed, line: str) -> None:
    try:
        ev = json.loads(line)
    except json.JSONDecodeError:
        return
    t, st = ev.get("type"), ev.get("subtype")
    if t == "system" and st == "init":
        p.init, p.session_id = ev, ev.get("session_id")
    elif t == "system" and st == "api_retry":
        p.retries.append(ev)
        if ev.get("error") == "authentication_failed":
            p.auth_failed = True
    elif t == "result":
        p.result = ev

def parse_stream(lines: Iterable[str]) -> Parsed:
    p = Parsed()
    for line in lines:
        feed(p, line)
    return p

@dataclass(frozen=True)
class Turn:
    pass_: str
    arm: str
    step: int
    attempt: int
    n: int
    image: str
    message: str
    env: dict[str, str]
    mounts: list[Mount]
    network: str
    proxy: bool
    workdir: str
    inbox: Path           # host dir mounted read-only at /inbox
    role: str = "arm"     # arm | po | teammate | setup | probe (part of the container name)

@dataclass
class TurnResult:
    session_id: str | None
    outcome: Outcome
    final_text: str
    init: dict
    result: dict | None
    cost_usd: float
    usage: dict
    model_usage: dict
    wall_seconds: float
    retries: list[dict]
    stream_path: Path

def container_name(t: Turn) -> str:
    return f"bk-{t.pass_}-{t.arm}-{t.step:02d}-{stem(t)}"

def stem(t: Turn) -> str:
    """File/container stem; includes the attempt so attempts never overwrite each other's files."""
    return f"{t.role}-a{t.attempt}-{t.n:03d}"

async def _run(t: Turn, cred: Credential, stream_path: Path, timeout_s: int) -> tuple[Parsed, str]:
    name = container_name(t)
    spec = RunSpec(name=name, image=t.image, label=f"bakeoff.run={t.pass_}/{t.arm}", network=t.network,
                   mounts=[*t.mounts, Mount(t.inbox, "/inbox", True)], env=t.env, workdir=t.workdir,
                   cmd=["bk-claude-turn", f"/inbox/{stem(t)}.md"], stdin=True,
                   limits=load_pins().limits, proxy=t.proxy)
    proc = await asyncio.create_subprocess_exec(*docker.run_argv(spec), stdin=asyncio.subprocess.PIPE,
                                                stdout=asyncio.subprocess.PIPE, stderr=asyncio.subprocess.PIPE,
                                                start_new_session=True, limit=64 * 1024 * 1024)
    proc.stdin.write(cred.payload()); await proc.stdin.drain(); proc.stdin.close()
    parsed, how = Parsed(), "exited"
    with gzip.open(stream_path, "wt") as out:
        async def pump():
            async for raw in proc.stdout:
                line = raw.decode(errors="replace")
                out.write(line); feed(parsed, line)
                if parsed.auth_failed:
                    return
        try:
            await asyncio.wait_for(pump(), timeout=timeout_s)
            if parsed.auth_failed:
                how = "auth_failed"
        except asyncio.TimeoutError:
            how = "timeout"
    if how != "exited":
        docker.stop(name)
    await proc.wait()
    return parsed, how

def run_turn(t: Turn, cred: Credential, out_dir: Path, timeout_s: int) -> TurnResult:
    (out_dir / "turns").mkdir(parents=True, exist_ok=True)
    t.inbox.mkdir(parents=True, exist_ok=True)
    (t.inbox / f"{stem(t)}.md").write_text(t.message)
    (out_dir / "turns" / f"{stem(t)}.prompt.md").write_text(t.message)
    stream = out_dir / "turns" / f"{stem(t)}.stream.jsonl.gz"
    start = time.monotonic()
    parsed, how = asyncio.run(_run(t, cred, stream, timeout_s))
    outcome: Outcome = "timeout" if how == "timeout" else parsed.outcome
    r = parsed.result or {}
    return TurnResult(parsed.session_id, outcome, parsed.final_text, parsed.init, parsed.result, parsed.cost_usd,
                      r.get("usage", {}), r.get("modelUsage", {}), time.monotonic() - start, parsed.retries, stream)
```

```python
# runner/transcripts.py
from __future__ import annotations
import gzip, hashlib, json, shutil
from dataclasses import dataclass, asdict, field
from pathlib import Path
from runner.config import Pins

def _open(p: Path):
    return gzip.open(p, "rt") if p.suffix == ".gz" else open(p)

def snapshot(config_dir: Path) -> dict[str, str]:
    root = config_dir / "projects"
    if not root.exists():
        return {}
    return {str(f.relative_to(root)): hashlib.sha256(f.read_bytes()).hexdigest()
            for f in sorted(root.rglob("*.jsonl"))}

def collect(config_dir: Path, before: dict[str, str], dest: Path) -> list[Path]:
    root, out = config_dir / "projects", []
    for rel, digest in snapshot(config_dir).items():
        if before.get(rel) == digest:
            continue
        target = dest / (rel + ".gz"); target.parent.mkdir(parents=True, exist_ok=True)
        with open(root / rel, "rb") as src, gzip.open(target, "wb") as dst:
            shutil.copyfileobj(src, dst)
        out.append(target)
    return out

@dataclass
class PinReport:
    ok: bool
    assistant_messages: int
    synthetic: int
    violations: list[dict] = field(default_factory=list)
    def to_json(self) -> str:
        return json.dumps(asdict(self), indent=2)

def verify_pin(transcript_files: list[Path], stream_files: list[Path], pins: Pins) -> PinReport:
    ok_models, synth = set(pins.accepted_models), set(pins.synthetic_models)
    n = s = 0; bad: list[dict] = []
    def judge(f, i, where, model):
        nonlocal s
        if model in synth:
            s += 1
        elif model not in ok_models:
            bad.append({"file": str(f), "line": i, "where": where, "model": model})
    for f in transcript_files:
        with _open(f) as fh:
            for i, line in enumerate(fh, 1):
                ev = json.loads(line)
                if ev.get("type") == "assistant":
                    n += 1; judge(f, i, "assistant", (ev.get("message") or {}).get("model"))
    for f in stream_files:
        with _open(f) as fh:
            for i, line in enumerate(fh, 1):
                ev = json.loads(line)
                if ev.get("type") == "system" and ev.get("subtype") == "init":
                    judge(f, i, "init", ev.get("model"))
                elif ev.get("type") == "result":
                    for m in (ev.get("modelUsage") or {}):
                        judge(f, i, "result.modelUsage", m)
    return PinReport(ok=not bad and (n > 0 or not transcript_files) and bool(transcript_files or stream_files),
                     assistant_messages=n, synthetic=s, violations=bad)
```
Note on the last test: a report with no transcripts and no streams at all is `ok == False` ("not evidence"),
and the runner treats a step with zero assistant messages as a harness fault (`model-pin:no-evidence`).

```python
# runner/repo.py
from __future__ import annotations
import json, os, shutil, subprocess, tarfile
from dataclasses import dataclass
from pathlib import Path
from runner import config
from runner.paths import Paths

ORG = "troupe-run"

def _git(repo: Path, *a: str, check: bool = True) -> str:
    return subprocess.run(["git", "-C", str(repo), *a], capture_output=True, text=True, check=check).stdout.strip()

def github_slug(pass_: str, arm: str) -> str | None:
    if pass_ == "pass1":
        return f"{ORG}/bakeoff-specs-{arm}-pass1"
    if pass_ == "pass2":
        return f"{ORG}/bakeoff-specs-{arm}"
    return None

def init(p: Paths, arm: str, pass_: str) -> str:
    if p.base.exists():
        raise FileExistsError(f"{p.base} exists; a pass starts from nothing (OD20)")
    for d in (p.home / ".claude", p.repo, p.inbox, p.snapshots):
        d.mkdir(parents=True)
    ident = f"[user]\n\tname = bakeoff-{arm}\n\temail = bakeoff-{arm}@troupe.run\n[init]\n\tdefaultBranch = main\n" \
            f"[safe]\n\tdirectory = *\n"
    (p.home / ".gitconfig").write_text(ident)
    env = {**os.environ, "GIT_CONFIG_GLOBAL": str(p.home / ".gitconfig")}
    run = lambda *a: subprocess.run(["git", "-C", str(p.repo), *a], check=True, capture_output=True, env=env)
    run("init", "-q", "-b", "main")
    run("commit", "-q", "--allow-empty", "-m", "Initial commit")
    if slug := github_slug(pass_, arm):
        run("remote", "add", "origin", f"https://github.com/{slug}.git")
    return head(p)

def head(p: Paths) -> str:
    return _git(p.repo, "rev-parse", "HEAD")

@dataclass(frozen=True)
class RepoState:
    branch: str
    dirty: bool
    head: str

def state(p: Paths) -> RepoState:
    return RepoState(_git(p.repo, "branch", "--show-current"),
                     bool(_git(p.repo, "status", "--porcelain")), head(p))

def _snap_name(step: int | str) -> str:
    return f"step-{step:02d}.tar" if isinstance(step, int) else f"step-{step}.tar"

def snapshot(p: Paths, step: int | str) -> Path:
    p.snapshots.mkdir(parents=True, exist_ok=True)
    out = p.snapshots / _snap_name(step)
    with tarfile.open(out, "w") as tf:
        tf.add(p.home, arcname="home"); tf.add(p.work, arcname="work")
    return out

def restore(p: Paths, step: int | str) -> None:
    src = p.snapshots / _snap_name(step)
    shutil.rmtree(p.home); shutil.rmtree(p.work)
    with tarfile.open(src) as tf:
        tf.extractall(p.base, filter="tar")

def export(p: Paths, sha: str, dest: Path) -> None:
    dest.mkdir(parents=True, exist_ok=True)
    archive = subprocess.run(["git", "-C", str(p.repo), "archive", sha], capture_output=True, check=True).stdout
    subprocess.run(["tar", "-x", "-C", str(dest)], input=archive, check=True)

def bundle(p: Paths, dest: Path) -> None:
    dest.parent.mkdir(parents=True, exist_ok=True)
    _git(p.repo, "bundle", "create", str(dest), "--all")

def github_plan(pass_: str) -> list[str]:
    out = []
    for arm in config.all_arms():
        a = config.load_arm(arm)
        out.append(f'gh repo create {github_slug(pass_, arm)} --private '
                   f'--description "bakeoff-specs arm: {a.tool} {a.version} ({pass_})"')
    return out

def github_verify(pass_: str) -> dict:
    res = {}
    for arm in config.all_arms():
        r = subprocess.run(["gh", "repo", "view", github_slug(pass_, arm), "--json",
                            "visibility,hasIssuesEnabled,isEmpty"], capture_output=True, text=True)
        res[arm] = json.loads(r.stdout) if r.returncode == 0 else {"error": r.stderr.strip()}
    return res

def publish(p: Paths, pass_: str, ask) -> bool:
    slug = github_slug(pass_, p.arm)
    if not slug or not ask(f"Push {p.repo} main to {slug}? [y/N] "):
        return False
    subprocess.run(["git", "-C", str(p.repo), "push", "origin", "main"], check=True)
    return True
```

`runner github-plan pass1` prints the seven `gh repo create` lines and then the PAT instructions (OD16).

```python
# runner/commands.py
from __future__ import annotations
import json, re
from pathlib import Path

def installed(repo: Path, config_dir: Path) -> set[str]:
    out: set[str] = set()
    for f in (repo / ".claude" / "commands").rglob("*.md"):
        rel = f.relative_to(repo / ".claude" / "commands").with_suffix("")
        out.add("/" + ":".join(rel.parts))
    for f in (repo / ".claude" / "skills").glob("*/SKILL.md"):
        out.add("/" + f.parent.name)
    for manifest in (config_dir / "plugins").rglob(".claude-plugin/plugin.json"):
        root, name = manifest.parent.parent, json.loads(manifest.read_text())["name"]
        for f in (root / "skills").glob("*/SKILL.md"):
            out |= {f"/{name}:{f.parent.name}", f"/{f.parent.name}"}
        for f in (root / "commands").rglob("*.md"):
            out |= {f"/{name}:{f.stem}", f"/{f.stem}"}
    return out

_LEAD = re.compile(r"^\s*(/[A-Za-z0-9][\w.:-]*)")

def leading(text: str) -> str | None:
    m = _LEAD.match(text)
    return m.group(1) if m else None
```

```python
from __future__ import annotations
import re
from runner.config import Arm

_LAST = re.compile(r"^Contract sections (in force|added): (.+)\.\s*$", re.M)
_FROM = re.compile(r"\(from step (\d)")
_ONLY = re.compile(r"\(step 1 and 2\)")

def norm(name: str) -> str:
    return name.replace("`", "").split("(")[0].strip()

def contract_sections(text: str) -> dict[str, str]:
    parts = re.split(r"(?m)^(?=## )", text)
    return {norm(p.splitlines()[0][3:]): p.rstrip("\n") for p in parts if p.startswith("## ")}

def named(brief: str) -> tuple[str, list[str]]:
    m = list(_LAST.finditer(brief))[-1]
    return m.group(1), [n.strip() for n in m.group(2).split(";")]

def compose(step: int, brief: str, contract: str) -> str:
    secs = contract_sections(contract)
    _, names = named(brief)
    body = "\n\n".join(secs[norm(n)] for n in names)
    return f"{brief.rstrip()}\n\n---\n\n{body}\n"

def issue_body(brief: str) -> str:
    return _LAST.sub("", brief).rstrip() + "\n"

def bug_message(ref: str, contract: str) -> str:
    return (f"A bug has been reported in our tracker: {ref}. Please handle it.\n\n"
            f"Contract sections added: Aliases.\n\n---\n\n{contract_sections(contract)['Aliases']}\n")

def in_force(step: int, contract: str) -> str:
    keep = []
    for name, sec in contract_sections(contract).items():
        head = sec.splitlines()[0]
        m = _FROM.search(head)          # checked first: the step-3 heading also quotes "(step 1 and 2)"
        if m:
            ok = int(m.group(1)) <= step
        else:
            ok = bool(_ONLY.search(head)) and step <= 2
        if ok:
            keep.append(sec)
    return "\n\n".join(keep) + "\n"

def entry_message(arm: Arm, step: int, handoff_text: str) -> str:
    template = arm.bug_entry if step == 6 else arm.entry
```

```python
from __future__ import annotations
import json, re, shutil, subprocess
from dataclasses import dataclass, asdict
from datetime import datetime, timezone
from pathlib import Path
from runner import config, credentials, egress, session
from runner.docker import Mount
from runner.paths import Paths, STATE

KINDS = {"question", "approval", "next_command", "continue", "step_done"}
PROTOCOL = config.CONFIG_DIR / "po-protocol.md"
CONTINUE = "Please continue."

def PO_IMAGE(pins) -> str:
    """The PO runs real Claude in the base image; dry passes swap in the fake (set by orchestrate for dry arms)."""
    return pins.images["dryrun"] if _DRY else pins.images["base"]

_DRY = False   # set True only by orchestrate.run_pass for dry passes

class ProtocolError(ValueError):
    pass

@dataclass(frozen=True)
class Decision:
    kind: str
    reply: str | None
    escalate: bool
    escalation_question: str | None
    cited: str | None
    approved: bool | None
    significant: bool

def _extract(text: str) -> dict:
    m = re.search(r"\{.*\}", text, re.S)
    if not m:
        raise ProtocolError("no JSON object in PO reply")
    try:
        return json.loads(m.group(0))
    except json.JSONDecodeError as e:
        raise ProtocolError(f"PO reply is not valid JSON: {e}") from e

def parse(text: str) -> Decision:
    o = _extract(text)
    try:
        d = Decision(o["kind"], o.get("reply"), bool(o.get("escalate")), o.get("escalation_question"),
                     o.get("cited"), o.get("approved"), bool(o.get("significant")))
    except KeyError as e:
        raise ProtocolError(f"missing {e}") from e
    if d.kind not in KINDS:
        raise ProtocolError(f"unknown kind {d.kind!r}")
    if d.escalate:
        if d.kind != "question" or d.reply is not None or not d.escalation_question:
            raise ProtocolError("an escalation has kind question, reply null and an escalation_question")
    elif d.kind in {"question", "approval", "next_command", "continue"} and not d.reply:
        raise ProtocolError(f"{d.kind} needs a reply")
    if d.kind == "approval" and d.approved is None:
        raise ProtocolError("approval needs approved true/false")
    if d.kind == "next_command" and not d.reply.startswith("/"):
        raise ProtocolError("next_command reply must be a slash command")
    if d.kind == "continue" and d.reply != CONTINUE:
        raise ProtocolError("continue reply must be exactly 'Please continue.'")
    if d.kind == "step_done" and d.reply is not None:
        raise ProtocolError("step_done has reply null")
    return d

@dataclass
class PoContext:
    pass_: str
    arm: str
    step: int
    attempt: int
    paths: Paths
    contract_in_force: str
    step_brief: str
    qa_so_far: list[dict]
    out_dir: Path

def _qa_md(qa: list[dict]) -> str:
    return "\n\n".join(f"Q{i}: {q['arm_message']}\nA{i} ({q['answered_by']}): {q['reply']}"
                       for i, q in enumerate(qa, 1)) or "(nothing yet)"

def decide(ctx: PoContext, arm_message: str, cred, n: int, brief_path: Path) -> tuple[Decision, "session.TurnResult"]:
    pins, arm = config.load_pins(), config.load_arm(ctx.arm)
    d = ctx.out_dir / "po" / f"{n:03d}"; d.mkdir(parents=True, exist_ok=True)
    shutil.copy(PROTOCOL, d / "protocol.md"); shutil.copy(brief_path, d / "po-brief.md")
    (d / "contract.md").write_text(ctx.contract_in_force); (d / "step.md").write_text(ctx.step_brief)
    (d / "qa.md").write_text(_qa_md(ctx.qa_so_far)); (d / "message.md").write_text(arm_message)
    home = STATE / ctx.pass_ / "po-home"; (home / ".claude").mkdir(parents=True, exist_ok=True)
    last_err = None
    for attempt_no in (1, 2):
        msg = "Read /po/protocol.md and follow it."
        if last_err:
            msg += f"\n\nYour previous reply could not be used ({last_err}). Reply with one JSON object only."
        with egress.Stage(ctx.pass_, ctx.arm, "po", pins.egress_po, ctx.out_dir / "egress-po.log") as st:
            t = session.Turn(ctx.pass_, ctx.arm, ctx.step, ctx.attempt, n * 10 + attempt_no, PO_IMAGE(pins), msg,
                             credentials.session_env(pins, arm, isolated=True, tools="Read,Glob,Grep"),
                             [Mount(home, "/home/actor", False),
                              Mount(ctx.paths.repo, ctx.paths.container_repo, True), Mount(d, "/po", True)],
                             st.net, True, ctx.paths.container_repo, ctx.paths.inbox, role="po")
            r = session.run_turn(t, cred, d, pins.limits.turn_seconds)
        if r.outcome != "ok":
            raise ProtocolError(f"PO session outcome {r.outcome}")
        try:
            dec = parse(r.final_text)
            (d / "decision.json").write_text(json.dumps(asdict(dec), indent=2))
            return dec, r
        except ProtocolError as e:
            last_err = str(e)
    raise ProtocolError(last_err)

def append_escalation(brief: Path, question: str, answer: str, pass_: str, arm: str, step: int) -> None:
    today = datetime.now(timezone.utc).date().isoformat()
    line = (f"- **Q:** {question} **A:** {answer} "
            f"_({today}; {pass_}; first raised by {arm} at step {step})_\n")
    text = brief.read_text()
    if "## Escalated answers" not in text:
        raise ValueError("brief has no '## Escalated answers' section")
    brief.write_text(text.rstrip("\n") + "\n" + line)

def commit_brief(brief: Path, pass_: str, arm: str, step: int) -> None:
    """Real passes only: the brief is harness state and its history is evidence."""
    if pass_ not in ("pass1", "pass2"):
        return
    repo = brief.parents[1]
    subprocess.run(["git", "-C", str(repo), "add", str(brief)], check=True)
    subprocess.run(["git", "-C", str(repo), "commit", "-q", "-m",
                    f"PO brief: escalated answer ({pass_}, {arm} step {step})"], check=True)
```

```python
from __future__ import annotations
import dataclasses, gzip, json, re, subprocess, tomllib
from dataclasses import dataclass, field
from datetime import datetime, timezone
from pathlib import Path
from typing import Literal
from runner import commands, config, credentials, egress, po, repo, session
from runner.config import Arm, Pins
from runner.docker import Mount
from runner.faults import HarnessFault
from runner.paths import Paths

MESSAGES = tomllib.loads((config.CONFIG_DIR / "scenario.toml").read_text())["messages"]

@dataclass
class StepCtx:
    pass_: str
    arm: Arm
    step: int
    paths: Paths
    pins: Pins
    out: Path
    contract_in_force: str
    step_brief: str
    brief_path: Path
    cred: credentials.Credential
    owner: object

@dataclass
class AttemptResult:
    outcome: Literal["done", "stalled", "timeout"]
    session_id: str | None
    turns: list = field(default_factory=list)
    po_turns: list = field(default_factory=list)
    exchanges: int = 0
    interventions: list[str] = field(default_factory=list)

def _now() -> str:
    return datetime.now(timezone.utc).isoformat(timespec="seconds").replace("+00:00", "Z")

def _invoked(cmd: str, turns: list) -> bool:
    name = cmd.lstrip("/")
    for t in turns:
        if not t.stream_path:
            continue
        with gzip.open(t.stream_path, "rt") as fh:
            for line in fh:
                if '"tool_use"' in line and name in line:
                    ev = json.loads(line)
                    for c in (ev.get("message") or {}).get("content", []):
                        if c.get("type") == "tool_use" and c.get("name") == "Skill" and \
                                str((c.get("input") or {}).get("skill", "")).endswith(name):
                            return True
    return False

def _diffstat(p: Paths) -> str:
    return subprocess.run(["git", "-C", str(p.repo), "diff", "--stat", "HEAD"], capture_output=True, text=True).stdout

def run_attempt(ctx: StepCtx, attempt: int, message: str, resume: str | None = None) -> AttemptResult:
    pins, arm, p = ctx.pins, ctx.arm, ctx.paths
    res = AttemptResult("stalled", resume)
    qa_path = ctx.out / "questions.jsonl"; qa_path.parent.mkdir(parents=True, exist_ok=True)
    qa = [json.loads(l) for l in qa_path.read_text().splitlines()] if qa_path.exists() else []
    sent: list[str] = []
    nudged = False
    mounts = [Mount(p.home, "/home/actor", False), Mount(p.work, "/work", False)]
    hosts = pins.egress_run_common + arm.egress_run
    with egress.Stage(ctx.pass_, arm.name, "run", hosts, ctx.out / "egress.log") as st:
        while True:
            n = len(list((ctx.out / "turns").glob(f"arm-a{attempt}-*.prompt.md"))) + 1
            image = pins.images["dryrun"] if arm.dry else arm.image
            env = credentials.session_env(pins, arm, isolated=False, resume=res.session_id or "")
            t = session.Turn(ctx.pass_, arm.name, ctx.step, attempt, n, image, message, env, mounts, st.net, True,
                             p.container_repo, p.inbox)
            r = session.run_turn(t, ctx.cred, ctx.out, pins.limits.turn_seconds)
            res.turns.append(r)
            if r.outcome == "timeout":
                res.outcome = "timeout"; return res
            if r.outcome in ("auth_failed", "no_result"):
                raise HarnessFault(f"infra-{r.outcome}", r.outcome, f"turn {n}")
            if r.outcome == "is_error":
                raise HarnessFault("infra-api", re.sub(r"\d", "", r.final_text.splitlines()[0] if r.final_text else "")[:80],
                                   r.final_text[:500])
            res.session_id = r.session_id or res.session_id
            res.exchanges += 1
            if res.exchanges > pins.limits.exchanges_per_attempt:
                res.outcome = "stalled"; return res
            try:
                dec, pr = po.decide(po.PoContext(ctx.pass_, arm.name, ctx.step, attempt, p, ctx.contract_in_force,
                                                 ctx.step_brief, qa, ctx.out), r.final_text, ctx.cred, n, ctx.brief_path)
            except po.ProtocolError as e:
                raise HarnessFault("po-protocol", "unparseable", str(e)) from e
            res.po_turns.append(pr)
            entry = {"attempt": attempt, "n": n, "at": _now(), "arm_message": r.final_text, "kind": dec.kind,
                     "escalated": dec.escalate, "escalation_question": dec.escalation_question,
                     "significant": dec.significant, "cited": dec.cited, "approved": dec.approved,
                     "answered_by": "po", "owner_action": None, "owner_seconds": 0.0, "po_cost_usd": pr.cost_usd}
            if dec.kind == "question" and dec.escalate:
                reply, secs = ctx.owner.escalation(dec.escalation_question, r.final_text)
                po.append_escalation(ctx.brief_path, dec.escalation_question, reply, ctx.pass_, arm.name, ctx.step)
                po.commit_brief(ctx.brief_path, ctx.pass_, arm.name, ctx.step)
                entry |= {"answered_by": "owner", "owner_seconds": secs}
            elif dec.kind == "approval":
                reply, action, secs = ctx.owner.gate(r.final_text, dec, _diffstat(p))
                entry |= {"answered_by": "po" if action == "accept" else "owner", "owner_action": action,
                          "owner_seconds": secs}
                with open(ctx.out / "owner-gates.jsonl", "a") as fh:
                    fh.write(json.dumps({**entry, "po_verdict": dec.reply, "final_reply": reply}) + "\n")
            elif dec.kind == "next_command":
                lead = commands.leading(dec.reply)
                if lead in commands.installed(p.repo, p.home / ".claude"):
                    reply = dec.reply; sent.append(lead)
                else:
                    reply = MESSAGES["continue"]; res.interventions.append(f"next_command-not-installed:{dec.reply}")
            elif dec.kind == "continue":
                reply = MESSAGES["continue"]
            else:  # step_done
                pending = [c for c in arm.must_run if c not in sent and not _invoked(c, res.turns)]
                s = repo.state(p)
                if pending:
                    reply = pending[0]; sent.append(pending[0]); entry["answered_by"] = "runner"
                elif (s.dirty or s.branch != "main") and not nudged:
                    reply = MESSAGES["commit_on_main"]; nudged = True; entry["answered_by"] = "runner"
                    res.interventions.append("commit_on_main")
                else:
                    entry["reply"] = None; qa.append(entry)
                    with open(qa_path, "a") as fh: fh.write(json.dumps(entry) + "\n")
                    res.outcome = "done"; return res
            entry["reply"] = reply; qa.append(entry)
            with open(qa_path, "a") as fh:
                fh.write(json.dumps(entry) + "\n")
            message = reply

def replace_limits(pins: Pins, **kw) -> Pins:
    return dataclasses.replace(pins, limits=dataclasses.replace(pins.limits, **kw))
```

### Task 13: The unannounced step-2 hand edit (OD1)

**What it is, concretely.** Before the step-2 brief is handed over, a "teammate" commits a small feature

```python
def scope_ok(porcelain: str) -> bool:
    lines = [l for l in porcelain.splitlines() if l.strip()]
    return bool(lines) and all(l[:2].strip() in ("M", "A", "??") and l[3:].endswith(".py") for l in lines)

    return {"feature_kept": probe_ok, "documented_in": sorted(non_py_mentions),
            "mentioned_in_session": session_mentions > 0, "raised_with_po": po_mentions > 0,
            "teammate_test_kept": teammate_test_kept}
```

```python
# runner/hidden.py (parsing + summary; container calls follow the interface above)
from __future__ import annotations
import json, os, xml.etree.ElementTree as ET
from dataclasses import dataclass, asdict, field
from pathlib import Path
from runner.paths import REPO_ROOT

ALLOW = {l.split("#")[0].strip() for l in (REPO_ROOT / "harness/negative_allowlist.txt").read_text().splitlines()
         if l.split("#")[0].strip()}

def parse_junit(xml: str) -> dict[str, str]:
    out = {}
    for tc in ET.fromstring(xml).iter("testcase"):
        o = "failed" if tc.find("failure") is not None or tc.find("error") is not None else \
            "skipped" if tc.find("skipped") is not None else "passed"
        out[f"{tc.get('classname')}::{tc.get('name')}"] = o
    return out

def flake_verdict(outcomes: list[str]) -> str:
    return "failed" if all(o == "failed" for o in outcomes) else "flaky"

@dataclass
class Summary:
    step: int
    total: int
    passed: int
    failed: int
    flaky: int
    tests: dict[str, str]
    new_at_step: list[str]
    new_passed: int
    new_discriminating_passed: int
    exit_code: int
    def write(self, out_dir: Path) -> None:
        (out_dir / "hidden").mkdir(parents=True, exist_ok=True)
        (out_dir / "hidden" / "summary.json").write_text(json.dumps(asdict(self), indent=2, sort_keys=True))

def summarise(step: int, tests: dict[str, str], new_at_step: list[str], flaky: list[str], exit_code: int) -> Summary:
    final = {t: ("flaky" if t in flaky else o) for t, o in tests.items()}
    new = [t for t in new_at_step if t in final]
    return Summary(step, len(final), sum(o == "passed" for o in final.values()),
                   sum(o == "failed" for o in final.values()), sum(o == "flaky" for o in final.values()),
                   final, new, sum(final[t] == "passed" for t in new),
                   sum(final[t] == "passed" and t.split("::")[-1] not in ALLOW for t in new), exit_code)
```

### Task 18: Stop rules — harness faults vs arm faults, attempts, halt (design §9)

**Files:**
- Modify: `runner/faults.py` (ledger, classification, halt), `runner/cli.py` (`faults list`, `faults declare
  <pass> <arm> <step> <slug> --scope rerun-step|retest`, `faults resume --note "<text>"`)
- Create: `runner/stepflow.py` (one step = attempts + tests + evidence; used by Task 19),
  `tests/runner/test_faults.py`, `tests/runner/test_stepflow.py`

**Classification (the runner's rules; Review Focus 4):**

| Signal | Class | `kind:signature` | What happens |
|---|---|---|---|
| a transcript/stream model outside `accepted_models` | harness | `model-pin:<model>` | restore the step snapshot, re-run the step |
| a step with zero assistant messages | harness | `model-pin:no-evidence` | re-run the step |
| `auth_failed` / `no_result` / `is_error` (API) | harness | `infra-<outcome>[:<msg>]` | re-run the step |
| a docker or proxy error raised by the runner | harness | `infra-container:<msg>` | re-run the step |
| PO reply unusable twice | harness | `po-protocol:unparseable` | re-run the step |
| hand edit out of scope / probe fails / changes hidden results (twice) | harness | `hand-edit:<which>` | re-run step 2 from `02-pre-edit` |
| a hidden test that is `flaky` | harness | `flaky-test:<nodeid>` | the owner fixes the test; **re-test only** (same SHA, no new arm session) |
| owner-declared (wrong brief, allowlist too narrow for a documented operation, runner bug) | harness | `manual:<slug>` | the owner picks `rerun-step` or `retest` |
| attempt ends `timeout` or `stalled` | arm | — | counts as an attempt; the hidden tests run on whatever is committed |
| `new_discriminating_passed == 0` after an attempt | arm (no progress) | — | the next attempt gets `messages.no_progress` in the same session; after **3** such attempts the arm **stops at this step** (OD3) |
| `install_failed` (the arm's project does not install) | arm | — | recorded; counts as no progress |

- **Halt rule:** every harness fault is appended to `results/faults.jsonl` (global, across passes):
  `{at, pass, arm, step, attempt, kind, signature, detail, action}`. When a `(kind, signature)` occurs for
  the **second** time since its last owner resolution, the runner writes `results/HALTED` with both
  entries and refuses every command except `faults …` until `faults resume --note` records a resolution.
  (Design §9: "the same harness fault twice halts the whole bake-off".) The first occurrence also pauses for
  the owner (`Re-run now? [Y/n]`), because design §9 says harness faults are *fixed* and then re-run.
- A harness-faulted attempt's evidence (turns, transcripts, PO files, questions, hidden results) moves to
  `NN/attempts/<k>-harness-<kind>/` and is never counted against the arm. A no-progress attempt keeps its
  turns and questions at the top level, because the arm's session continues into the next attempt; only its
  hidden results and an `attempt.json` move to `NN/attempts/<k>-no-progress/`.
- Arm stop: `results/<pass>/<arm>/arm-result.json` gets `{"stopped_at": N, "reason": "no progress in 3
  attempts", "last_hidden": {...}}`. The remaining steps are not run for that arm in that pass, and the
  report records the stop as the arm's result (design §9).

**Interfaces:**
- Produces: `faults.record(fault: HarnessFault, pass_, arm, step, attempt) -> Literal["rerun","halt"]`;
  `faults.halted() -> str | None`; `faults.resume(note)`; `faults.classify_pin(report) -> HarnessFault | None`;
  `stepflow.run_step(ctx, first_message) -> StepOutcome(status: Literal["done","stopped"], attempts: int,
  hidden: Summary)`, which contains the attempt loop, the harness re-run loop, hidden tests, quality and
  evidence.

```python
# runner/faults.py (ledger part)
from __future__ import annotations
import json
from datetime import datetime, timezone
from typing import Literal
from runner.paths import FAULTS, HALTED

def _entries() -> list[dict]:
    return [json.loads(l) for l in FAULTS.read_text().splitlines()] if FAULTS.exists() else []

def record(f: "HarnessFault", pass_: str, arm: str, step: int, attempt: int) -> Literal["rerun", "halt"]:
    key = (f.kind, f.signature)
    since = []
    for e in _entries():
        if e.get("resolution"):
            since = []
        elif (e["kind"], e["signature"]) == key:
            since.append(e)
    entry = {"at": datetime.now(timezone.utc).isoformat(timespec="seconds"), "pass": pass_, "arm": arm,
             "step": step, "attempt": attempt, "kind": f.kind, "signature": f.signature, "detail": f.detail,
             "action": "halt" if since else "rerun"}
    FAULTS.parent.mkdir(parents=True, exist_ok=True)
    with open(FAULTS, "a") as fh:
        fh.write(json.dumps(entry) + "\n")
    if since:
        HALTED.write_text(json.dumps({"reason": "same harness fault twice (design §9)", "first": since[-1],
                                      "second": entry}, indent=2))
        return "halt"
    return "rerun"

def halted() -> str | None:
    return HALTED.read_text() if HALTED.exists() else None

def resume(note: str) -> None:
    with open(FAULTS, "a") as fh:
        fh.write(json.dumps({"resolution": True, "note": note,
                             "at": datetime.now(timezone.utc).isoformat(timespec="seconds")}) + "\n")
    HALTED.unlink(missing_ok=True)
```
(A resolution resets every signature's count. That is deliberate: the owner reviewed the whole ledger
when resuming. Because `FAULTS` and `HALTED` are imported names, the test fixture patches them on the
`faults` module.)

`stepflow.run_step`, using only interfaces defined above (`faults.for_step` returns the ledger entries
for one step; `_park(out, k, label)` records `attempts/<k>-<label>/attempt.json` and moves that attempt's
`hidden/` there. For a **harness** label it also moves the attempt's `turns/*-a<k>-*`, `transcripts/a<k>/` and
`po/` files, and its `questions.jsonl` / `owner-gates.jsonl` lines, so a faulted attempt leaves nothing at
the top level. A no-progress attempt's turns and questions stay, because the arm's session continues;
`Halt` and `Paused` are exceptions that `orchestrate` turns into a clean stop with `progress.json` saved):
```python
def run_step(ctx, first_message, extra: dict[str, list] | None = None):
    """extra: turns made for this step outside the arm session (step 2's teammate), for cost and evidence."""
    attempt, message, resume, arm_attempts = 1, first_message, None, 0
    ar_history, extra = [], extra or {}
    sha_before, t0 = repo.head(ctx.paths), time.monotonic()
    while True:
        before = transcripts.snapshot(ctx.paths.home / ".claude")
        try:
            ar = drive.run_attempt(ctx, attempt, message, resume)
            pin = transcripts.verify_pin(transcripts.collect(ctx.paths.home / ".claude", before,
                                                             ctx.out / "transcripts" / f"a{attempt}"),
                                         [t.stream_path for t in ar.turns], ctx.pins)
            if (f := faults.classify_pin(pin)):
                raise f
        except HarnessFault as f:
            _park(ctx.out, attempt, f"harness-{f.kind}")
            if faults.record(f, ctx.pass_, ctx.arm.name, ctx.step, attempt) == "halt":
                raise Halt(faults.halted())
            if not ctx.owner.confirm(f"Harness fault {f.kind}: {f.signature}. Re-run step {ctx.step} now?"):
                raise Paused()
            repo.restore(ctx.paths, ctx.step)
            message, resume = first_message, None
            continue                                   # not an arm attempt
        arm_attempts += 1
        copy = hidden.prepare(ctx.paths, repo.head(ctx.paths), f"{ctx.step:02d}-a{arm_attempts}", ctx.out)
        summary = hidden.run(ctx.paths, copy, ctx.step, ctx.out)
        while summary.flaky:                           # flaky hidden test = harness fault; re-test only
            flaky = [t for t, o in summary.tests.items() if o == "flaky"]
            verdicts = [faults.record(HarnessFault("flaky-test", t), ctx.pass_, ctx.arm.name, ctx.step, arm_attempts)
                        for t in flaky]
            if "halt" in verdicts:
                raise Halt(faults.halted())
            if not ctx.owner.confirm(f"Flaky hidden test(s): {flaky}. Fix them, then confirm to re-test this commit."):
                raise Paused()
            summary = hidden.run(ctx.paths, copy, ctx.step, ctx.out)     # same SHA, no new arm session
        if summary.new_discriminating_passed > 0 or arm_attempts == ctx.pins.limits.attempts_no_progress:
            q = quality.run_all(ctx.paths, copy, ctx.out)
            evidence.finalise(ctx, attempts=ar_history + [ar], extra_turns=extra, hidden=summary, quality=q, pin=pin,
                              git_before=sha_before, git_after=repo.head(ctx.paths), started=t0, ended=time.monotonic(),
                              faults=faults.for_step(ctx.pass_, ctx.arm.name, ctx.step))
            status = "done" if summary.new_discriminating_passed > 0 else "stopped"
            return StepOutcome(status, arm_attempts, summary)
        _park(ctx.out, arm_attempts, "no-progress")
        ar_history.append(ar)
        message, resume = MESSAGES["no_progress"], ar.session_id
        attempt += 1
```
