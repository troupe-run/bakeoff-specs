# bakeoff-specs Plan 3 — scoring — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A staged, re-runnable scorer (`runner score <pass>`) that turns a pass's evidence into a traceable
scorecard with an explicit confidence check, a decision review the owner rates blind, and a summary-first report
(`report.md` + `scores.json` + an HTML page).

**Architecture:** A subpackage `runner/scoring/` of small single-purpose modules. Stages communicate only through
files under `results/<pass>/scoring/` (collect → decisions → anonymise → judge → aggregate → report), so each is
resumable and re-weighting re-runs only aggregate and report. Hand-written inputs (weights, "what goes stale"
lists, rubrics, excluded tests, phase rules) live in a top-level `scoring/` directory as TOML — single sources of
truth the owner can edit. Deterministic stages are pure functions over parsed evidence; the two LLM stages
(judge, decision extraction) go through one `Judge` protocol with a container implementation modelled on
`po.decide` and a fake for tests.

**Tech Stack:** Python 3.12 stdlib only (`tomllib`, `json`, `gzip`, `math`, `statistics`, `random`, `html`,
`dataclasses`) — `pyproject.toml`'s runtime `dependencies` stay `[]`. pytest. Docker only through existing
`runner.gitops` / `runner.hidden` / `runner.session` helpers.

**Spec:** [`docs/superpowers/specs/2026-10-05-scoring-design.md`](../specs/2026-10-05-scoring-design.md)
(owner-approved 2026-10-05 20:29). Also read [`docs/design.md`](../../design.md) §4–§9 for the scenario, the
people in the loop and the evidence layout.

## Global Constraints

- Weights, verbatim (spec §3): Coping with change 20 · Correctness 20 · Traceability 10 · Quality of human
  interaction 10 · Code and test quality 15 · Decision quality 10 · Setup and ergonomics 10 · Time to outcome 5.
  Sum 100. They live only in `scoring/weights.toml`.
- Part splits, verbatim: coping = regressions 7, stale artefacts updated 7, collateral churn 3, hand edit detected 3;
  decision quality = choice 6, process 4; setup = setup effort 4, fit 4, arm violations 2. Splits not given are equal.
- Scales (spec §4): pass rates and mutation score as is; mypy/lint as deductions with a floor; time and churn as
  log(arm ÷ control) for the same step, equal = midpoint, capped at 10× worse and 10× better; judged parts 0–4,
  median of three lenses. Every step weighs the same; a part is averaged over the steps it applies to.
- **Correctness counts all hidden tests at a step, earlier steps' included; regressions are also scored under
  coping. This double count is deliberate (owner). Do not "fix" it.**
- Missing or unreadable evidence is never a zero: it is recorded as `{"missing": "<path>", "why": "..."}` and
  shown. An unmeasured part's weight is shared among the dimension's measured parts; the cell is flagged.
- Python stdlib only; `pyproject.toml` `dependencies = []` stays empty.
- **The host never runs git (or anything else that reads repo-local config) against an arm repo.** Use
  `runner.gitops` (container) only — e.g. `gitops.numstat`, `gitops.export_tree`.
- Every `state/` or `results/` path is built in `runner/paths.py` and nowhere else (its module docstring).
- **While pass 1 runs: no Docker-heavy runs, no LLM calls, no runner lock.** Docker- or LLM-backed tests are
  marked `docker` / `live` and run only after pass 1 finishes (`--run-docker`, `--run-live`).
- Deterministic stages (collect, aggregate, report) write byte-identical output on a re-run: `json.dumps(...,
  indent=2, sort_keys=True)`, no timestamps, sorted iteration everywhere.
- The anonymisation key (`anon-key.json`) is never mounted into, or quoted to, a judge or the owner's blind
  rating view.
- Judge model: `claude-opus-5-5`, pinned and verified exactly as the PO is (`transcripts.verify_pin`).
- No test name claims more than its body asserts (owner rule). Never remove the `_no_real_keychain` autouse guard.
- Organisation in prose: "hps.gd".

## Review Focus

1. **An arm-step with no usable evidence** (interrupted, parked, a missing `hidden/summary.json`, an unparseable
   `run.json`): collect records `missing`, aggregate still completes, and the report shows the gap — never a
   zero, never a crash. Tested in Task 9 and Task 11.
2. **Control has no value for a step** (missing, or a time of 0): the log-ratio parts for that step are
   `missing` for every arm and flagged, not divided by zero. Tested in Task 11.
3. **Hidden tests that change identity between steps** (new at step N, excluded as a defect, renamed
   parametrisation): a regression is keyed by test id and counted only for a test that passed at N−1 and fails at
   N; excluded tests are dropped from both sides. Tested in Task 6.
4. **Truncated, unparseable or oversize transcript lines**: the phase classifier skips them, counts them in
   `skipped_lines`, and never crashes. Tested in Task 8.
5. **A judge reply that is not valid JSON, cites no evidence, or scores outside 0–4**: one retry, then recorded as
   `judge_failed` with the raw reply — never a score. Tested in Task 17.

```python
"""The JSON conventions every scoring stage shares: a value always carries its source; missing is never zero."""
from __future__ import annotations
import json


def val(value, source: str) -> dict:
    return {"value": value, "source": source}


def missing(source: str, why: str) -> dict:
    return {"missing": source, "why": why}


def is_missing(x) -> bool:
    return isinstance(x, dict) and "missing" in x


def dump(obj) -> str:
    """Byte-stable JSON: sorted keys, two-space indent, trailing newline (deterministic stages, spec §12)."""
    return json.dumps(obj, indent=2, sort_keys=True, ensure_ascii=False) + "\n"
```

```python
# runner/scoring/inputs.py
"""Load and validate the hand-written scoring inputs under `scoring/` (single sources of truth, owner-editable)."""
from __future__ import annotations
import tomllib
from dataclasses import dataclass
from pathlib import Path
from runner import paths


class InputError(ValueError):
    pass


@dataclass(frozen=True)
class Weights:
    dimensions: dict[str, float]
    parts: dict[str, dict[str, float]]          # dimension -> part -> points (dimensions without parts: absent)

    def part_share(self, dim: str, part: str) -> float:
        return self.parts[dim][part] / self.dimensions[dim]


def _toml(path: Path) -> dict:
    try:
        return tomllib.loads(path.read_text())
    except (OSError, tomllib.TOMLDecodeError) as e:
        raise InputError(f"{path}: {e}") from e


def load_weights(path: Path | None = None) -> Weights:
    path = path or paths.SCORING_INPUTS / "weights.toml"
    raw = _toml(path)
    dims = {k: float(v) for k, v in raw.get("dimensions", {}).items()}
    if abs(sum(dims.values()) - 100) > 1e-9:
        raise InputError(f"{path}: dimension weights must sum to 100, got {sum(dims.values())}")
    parts = {d: {k: float(v) for k, v in ps.items()} for d, ps in raw.get("parts", {}).items()}
    for d, ps in parts.items():
        if d not in dims:
            raise InputError(f"{path}: parts for unknown dimension {d!r}")
        if abs(sum(ps.values()) - dims[d]) > 1e-9:
            raise InputError(f"{path}: parts of {d} sum to {sum(ps.values())}, not {dims[d]}")
    return Weights(dims, parts)
```

```python
import fnmatch

_KINDS = {"requirement", "test", "doc", "code"}


@dataclass(frozen=True)
class StaleList:
    step: int
    stale: list[dict]
    legitimate: list[str]


def load_stale(step: int, root: Path | None = None) -> StaleList | None:
    if step == 1:
        return None
    path = (root or paths.SCORING_INPUTS / "stale") / f"step-{step:02d}.toml"
    raw = _toml(path)
    stale = raw.get("stale", [])
    for i in stale:
        if set(i) != {"id", "kind", "what", "why"} or i["kind"] not in _KINDS:
            raise InputError(f"{path}: bad stale item {i!r}")
    legit = raw.get("legitimate", {}).get("paths", [])
    if not legit:
        raise InputError(f"{path}: [legitimate] paths is empty")
    return StaleList(step, stale, legit)


def legitimate(path: str, s: StaleList) -> bool:
    """`**` matches across directories (fnmatch's `*` already does); patterns are repo-relative."""
    return any(fnmatch.fnmatch(path, pat) or fnmatch.fnmatch(path, pat.replace("/**", "")) for pat in s.legitimate)
```

```python
EVIDENCE_KINDS = {"repo", "diff", "stale_list", "transcript", "questions", "gates", "setup"}


@dataclass(frozen=True)
class Rubric:
    part: str
    dimension: str
    unit: str
    steps: tuple[int, ...]
    evidence: tuple[str, ...]
    levels: dict[int, str]
    lenses: tuple[dict, ...]


def load_rubrics(root: Path | None = None) -> dict[str, Rubric]:
    root = root or paths.SCORING_INPUTS / "rubrics"
    out: dict[str, Rubric] = {}
    for f in sorted(root.glob("*.toml")):
        raw = _toml(f)
        levels = {int(k): v for k, v in raw.get("levels", {}).items()}
        lenses = tuple(raw.get("lens", []))
        r = Rubric(part=f.stem, dimension=raw["dimension"], unit=raw.get("unit", "step"),
                   steps=tuple(raw.get("steps", range(1, 8))), evidence=tuple(raw["evidence"]),
                   levels=levels, lenses=lenses)
        if sorted(levels) != [0, 1, 2, 3, 4] or len(lenses) != 3 or not set(r.evidence) <= EVIDENCE_KINDS \
```

```python
"""Readers for one arm-step's evidence directory (results/<pass>/<arm>/<NN>/). Pure: no Docker, no git, no LLM.
Every reader returns values.val(...) or values.missing(...), never raises on bad evidence."""

from pathlib import Path
from runner import paths
from runner.scoring import values


def rel(p: Path) -> str:
    try:
        return str(p.relative_to(paths.REPO_ROOT))
    except ValueError:
        return str(p)

        return values.val(json.loads(p.read_text()), rel(p))
    except FileNotFoundError:

    except (OSError, json.JSONDecodeError) as e:

def all_fail(pass_dir: Path, arms: list[str]) -> dict[int, list[str]]:
    out: dict[int, list[str]] = {}
    for step in range(1, 8):
        failing: set[str] | None = None

            s = hidden_summary(pass_dir / arm / f"{step:02d}")
            if values.is_missing(s) or not s["value"].get("scoreable", True):
                continue
            f = {t for t, o in s["value"].get("tests", {}).items() if o != "passed"}
            failing = f if failing is None else failing & f
        if failing:
            out[step] = sorted(failing)
    return out
```

```python
import gzip, re

_ARM_STREAM = re.compile(r"^arm-a(\d+)-(\d+)\.stream\.jsonl\.gz$")


def run_record(step_dir: Path) -> dict:
    return read_json(step_dir / "run.json")


def _result_line(p: Path) -> dict | None:
    try:
        with gzip.open(p, "rt", errors="replace") as f:
            last = None
            for line in f:
                if '"type":"result"' in line.replace(" ", ""):
                    try:
                        last = json.loads(line)
                    except json.JSONDecodeError:
                        continue
            return last
    except (OSError, EOFError):
        return None


def arm_time(step_dir: Path) -> dict:
    td = step_dir / "turns"
    found = sorted((int(m[1]), int(m[2]), f) for f in (td.iterdir() if td.is_dir() else [])
                   if (m := _ARM_STREAM.match(f.name)))
    if not found:
        return values.missing(rel(td), "no arm turn streams")
    attempt = max(a for a, _, _ in found)
    turns, prev_usd, secs = [], 0.0, 0.0
    for _, _, f in (x for x in found if x[0] == attempt):
        r = _result_line(f)
        if r is None:
            return values.missing(rel(f), "no result line (turn did not finish)")
        usd = float(r.get("total_cost_usd") or 0.0)
        turns.append({"stem": f.name.removesuffix(".stream.jsonl.gz"), "seconds": r.get("duration_ms", 0) / 1000,
                      "usd": max(0.0, usd - prev_usd)})
        prev_usd, secs = usd, secs + r.get("duration_ms", 0) / 1000
    return values.val({"seconds": secs, "attempt": attempt, "turns": turns}, rel(td))


def costs(step_dir: Path) -> dict:
    b, a = read_json(step_dir / "cost.json"), read_json(step_dir / "a" / "cost.json")
    if values.is_missing(b):
        return b
    v = b["value"]
    return values.val({"scored_usd": v.get("arm", {}).get("usd"), "po_usd": v.get("po", {}).get("usd"),
                       "discovery_usd": None if values.is_missing(a) else a["value"].get("arm", {}).get("usd")},
                      b["source"])


def quality(step_dir: Path) -> dict:
    q = read_json(step_dir / "quality" / "summary.json")
    if values.is_missing(q):
        return q
    v, m = q["value"], q["value"].get("mutation", {})
    state = ("crashed" if m.get("crashed") else "baseline_failed" if m.get("baseline_failed")
             else "unmeasured" if m.get("score") is None else "measured")
    return values.val({"mypy_errors": None if v.get("mypy_crashed") else v.get("mypy_errors"),
                       "ruff_findings": None if v.get("ruff_crashed") else v.get("ruff_findings"),
                       "mutation_score": m.get("score"), "mutation_state": state}, q["source"])


def _jsonl(p: Path) -> list[dict]:
    try:
        return [json.loads(l) for l in p.read_text().splitlines() if l.strip()]
    except (OSError, json.JSONDecodeError):
        return []


def questions(step_dir: Path) -> dict:
    out = []
    for run, p in (("a", step_dir / "a" / "questions.jsonl"), ("b", step_dir / "questions.jsonl")):
        for q in _jsonl(p):
            out.append({"run": run, "n": q.get("n"), "kind": q.get("kind"), "answered_by": q.get("answered_by"),
                        "escalated": q.get("escalated", []), "fallback": q.get("fallback", [])})
    return values.val(out, rel(step_dir / "questions.jsonl"))


def violations(step_dir: Path) -> dict:
    r = run_record(step_dir)
    return r if values.is_missing(r) else values.val(r["value"].get("arm_violations", []), r["source"])
```

```python
# runner/scoring/regressions.py
"""Coping with change, regressions part: earlier steps' hidden tests that passed at N-1 and fail at N. Keyed by
test id, so new tests, renamed parametrisations and tests that already failed are never regressions."""
from __future__ import annotations


def compute(prev: dict[str, str] | None, cur: dict[str, str], excluded: frozenset[str]) -> dict:
    prev = {t: o for t, o in (prev or {}).items() if t not in excluded}
    earlier = [t for t in sorted(prev) if t in cur and t not in excluded]
    passing_before = [t for t in earlier if prev[t] == "passed"]
    regressed = [t for t in passing_before if cur[t] != "passed"]
    rate = None if not passing_before else 1 - len(regressed) / len(passing_before)
    return {"earlier_total": len(earlier), "earlier_passing_before": len(passing_before),
            "regressed": regressed, "rate": rate}
```

```python
# runner/scoring/churn.py
"""Coping with change, collateral churn: lines changed in files the step had no reason to touch (spec §3). The
step's legitimate paths (scoring/stale/step-NN.toml) plus the arm's own spec folders are never collateral."""
from __future__ import annotations
import fnmatch, re
from runner import config, gitops
from runner.paths import Paths
from runner.scoring import inputs, values

_BRACE = re.compile(r"\{([^{}]*) => ([^{}]*)\}")


def normalise(path: str) -> str:
    if _BRACE.search(path):
        return re.sub(r"//+", "/", _BRACE.sub(lambda m: m[2], path))
    return path.split(" => ", 1)[1] if " => " in path else path


def _spec(path: str, spec_paths) -> bool:
    return any(path.startswith(sp.path) if sp.path.endswith("/") else fnmatch.fnmatch(path, sp.path)
               for sp in spec_paths)


def collateral(rows, stale: inputs.StaleList, spec_paths) -> dict:
    lines, files, total = 0, [], 0
    for added, deleted, raw in rows:
        path, n = normalise(raw), added + deleted
        total += n
        if not inputs.legitimate(path, stale) and not _spec(path, spec_paths):
            lines += n
            files.append(path)
    return {"lines": lines, "files": sorted(set(files)), "total_lines": total}


def for_step(pass_: str, arm: str, git_json: dict, stale: inputs.StaleList | None) -> dict:
    """Docker (gitops runs git in a network-less container — the host never runs git on an arm repo)."""
    if stale is None:
        return values.missing(git_json.get("source", ""), "step 1: nothing to compare against")
    if values.is_missing(git_json):
        return git_json
    g = git_json["value"]
    try:
        rows = gitops.numstat(Paths(pass_, arm), g["sha_before"], g["sha_after"])
    except gitops.GitError as e:
        return values.missing(git_json["source"], f"numstat failed: {e}")
    return values.val(collateral(rows, stale, config.load_arm(arm).spec_paths), git_json["source"])
```

**Classification rules (encode exactly; they are the SSOT's semantics):**
1. Time between consecutive events goes to the phase of the earlier event (the last event of a session gets 0).
2. A `Write`/`Edit`/`NotebookEdit` to a path matching the arm's spec paths or `spec_globs` → `specify`; matching
   `test_globs` → `test`; any other path → `implement`.
3. A `Bash` whose command matches a `test_commands` regex → `test`. If its result `is_error` is true, or its
   output contains `failed`/`error` (case-insensitive, word-bounded), set **rework mode**.
4. In rework mode, rule 2's writes are `rework` instead. A later passing test command clears rework mode.
5. A `Skill`/`Task`/`Agent` call, or a turn whose method label, matches `review_markers` → `review`.
6. `Read`/`Grep`/`Glob`/other Bash before the first write of the turn → `understand`; after it, the phase of the
   most recent classified event.
7. `waiting` = `po_seconds + owner_wait_seconds` from `run.json`.
8. Phase `usd`: each turn's own cost (Task 5) is split across phases in proportion to that turn's seconds.

```python
# runner/scoring/phases.py
"""Time and cost by phase (spec §5): the method's own phases (one turn = one phase, labelled by its command) and
seven common phases classified from transcript events by the rules in scoring/phases.toml."""
from __future__ import annotations
import fnmatch, gzip, json, re
from datetime import datetime
from pathlib import Path
from runner import transcripts
from runner.scoring import evidence, values

PHASES = ("understand", "specify", "implement", "test", "rework", "review", "waiting")
_WRITE = {"Write", "Edit", "NotebookEdit", "MultiEdit"}
_FAILED = re.compile(r"(?i)\b(failed|error)\b")


def _match(path: str, globs) -> bool:
    return any(fnmatch.fnmatch(path, g) or fnmatch.fnmatch(path, g.replace("/**", "")) for g in globs)


def _spec(path, rules, spec_paths) -> bool:
    return _match(path, rules.spec_globs) or any(
        path.startswith(sp.path) if sp.path.endswith("/") else fnmatch.fnmatch(path, sp.path) for sp in spec_paths)


def _rel(path: str) -> str:
    return re.sub(r"^/work/[^/]+/", "", path or "")


def classify(events: list[dict], rules, spec_paths) -> dict:
    secs = {p: 0.0 for p in PHASES}
    rework, wrote, current, pending = False, False, "understand", {}
    tools = [e for e in events if e["kind"] in ("tool", "result")]
    for i, e in enumerate(tools):
        nxt = tools[i + 1]["t"] if i + 1 < len(tools) else e["t"]
        phase = current
        if e["kind"] == "result":
            if e["id"] in pending:                       # rules 3-4: a test result sets or clears rework mode
                rework = e["is_error"] or bool(_FAILED.search(e.get("output", "")))
                pending.pop(e["id"])
        else:
            name, inp = e["name"], e["input"] or {}
            if name in _WRITE:
                path = _rel(inp.get("file_path") or inp.get("notebook_path") or "")
                base = ("specify" if _spec(path, rules, spec_paths) else "test" if _match(path, rules.test_globs)
                        else "implement")
                phase, wrote = ("rework" if rework else base), True
            elif name == "Bash" and any(r.search(inp.get("command", "")) for r in rules.test_commands):
                phase = "test"
                if e.get("id"):
                    pending[e["id"]] = True
            elif name in ("Skill", "Task", "Agent") and any(
                    r.search(json.dumps(inp)) for r in rules.review_markers):
                phase = "review"
            elif not wrote:
                phase = "understand"
            current = phase
        secs[phase] += max(0.0, nxt - e["t"])
    return {"seconds": secs, "skipped_lines": 0}
```

```python
# runner/scoring/collect.py
"""Stage 1: every measured value per arm-step, each with its source path. Deterministic; no LLM."""
from __future__ import annotations
import re
from pathlib import Path
from runner import config, paths
from runner.scoring import STEPS, churn, evidence, inputs, phases, regressions, values

_STEP_DIR = re.compile(r"^\d\d$")


def arms(pass_dir: Path) -> list[str]:
    return sorted(d.name for d in pass_dir.iterdir()
                  if d.is_dir() and any(_STEP_DIR.match(c.name) for c in d.iterdir() if c.is_dir()))


def _spec_paths(arm: str) -> list:
    try:
        return config.load_arm(arm).spec_paths
    except Exception:                       # dry and fixture arms may have no config: no spec folders exempt
        return []


def _hidden(step_dir: Path, excl) -> tuple[dict, dict | None]:
    s = evidence.hidden_summary(step_dir)
    if values.is_missing(s) or not s["value"].get("scoreable", True):
        return (s if values.is_missing(s) else values.missing(s["source"], "not scoreable")), None
    tests = {t: o for t, o in s["value"].get("tests", {}).items()}
    kept = {t: o for t, o in tests.items() if t not in excl.defects}
    passed = sum(1 for o in kept.values() if o == "passed")
    return values.val({"passed": passed, "total": len(kept), "excluded": sorted(set(tests) - set(kept)),
                       "per_test": kept}, s["source"]), tests


def step(pass_: str, arm: str, n: int, *, prev_tests, excl, rules, docker: bool) -> tuple[dict, dict | None]:
    d = paths.RESULTS / pass_ / arm / f"{n:02d}"
    hidden, tests = _hidden(d, excl)
    run = evidence.run_record(d)
    git = evidence.read_json(d / "git.json")
    rec = {
        "arm": arm, "step": n,
        "outcome": run if values.is_missing(run) else values.val(run["value"].get("outcome"), run["source"]),
        "hidden": hidden,
        "regressions": (values.missing(hidden.get("missing", hidden.get("source", "")), "no hidden results")
                        if tests is None else
                        values.val(regressions.compute(prev_tests, tests, excl.defects), hidden["source"])),
        "quality": evidence.quality(d), "time": evidence.arm_time(d), "cost": evidence.costs(d),
        "questions": evidence.questions(d), "violations": evidence.violations(d),
        "churn": (churn.for_step(pass_, arm, git, inputs.load_stale(n)) if docker
                  else values.missing(git.get("source", git.get("missing", "")), "deferred: run with Docker after pass 1")),
        "phases": {"method": phases.method_phases(d),
                   "common": phases.common_phases(d, _spec_paths(arm), rules)},
    }
    return rec, tests


def run(pass_: str, *, docker: bool = True) -> list[Path]:
    excl, rules = inputs.load_excluded(), inputs.load_phase_rules()
    out_dir, written = paths.scoring_out(pass_) / "collected", []
    for arm in arms(paths.RESULTS / pass_):
        prev = None
        for n in STEPS:
            if not (paths.RESULTS / pass_ / arm / f"{n:02d}").is_dir():
                continue
            rec, tests = step(pass_, arm, n, prev_tests=prev, excl=excl, rules=rules, docker=docker)
            prev = tests if tests is not None else prev
            f = out_dir / arm / f"{n:02d}.json"
            f.parent.mkdir(parents=True, exist_ok=True)
            f.write_text(values.dump(rec))
            written.append(f)
    return written
```

```python
# runner/scoring/scales.py
"""Raw measurement -> 0..1 (spec §4). Natural scales as they are; control as the baseline where none exists."""
from __future__ import annotations
import math

_RATINGS = {"good": 1.0, "acceptable": 0.67, "poor": 0.0}


def ratio_score(arm: float | None, control: float | None, cap: float = 10.0) -> float | None:
    if not arm or not control or arm <= 0 or control <= 0:
        return None
    x = math.log10(arm / control) / math.log10(cap)          # +1 = cap times worse, -1 = cap times better
    return min(1.0, max(0.0, 0.5 - x / 2))


def churn_score(arm_lines: int, control_lines: int, cap: float = 10.0) -> float:
    return ratio_score(arm_lines + 1, control_lines + 1, cap)      # add-one: zero lines are defined


def deduction(count: int | None, per: float) -> float | None:
    return None if count is None else max(0.0, 1.0 - per * count)


def judged(score: float | None) -> float | None:
    return None if score is None else score / 4


def rating(r: str, table: dict[str, float] | None = None) -> float | None:
    return (table or _RATINGS).get(r)
```

  `{"weights": {...}, "baseline": str, "arms": {arm: {"total": float, "dimensions": {dim: {"score": float,

```python
# runner/scoring/aggregate.py
"""Stage: collected + judged + ratings + owner verdicts + weights -> scores.json (spec §3, §4, §6). Deterministic."""
from __future__ import annotations
import json, statistics
from pathlib import Path
from runner import paths
from runner.scoring import evidence, inputs, scales, values

ARM_LEVEL = {"violations", "choice", "setup_effort", "fit"}
MEASURED = {"correctness", "regressions", "churn", "time", "mutation", "mypy_lint", "violations", "choice"}


def _v(x):
    return None if x is None or values.is_missing(x) else x["value"]


def _collected(pass_: str) -> dict[str, dict[int, dict]]:
    out: dict[str, dict[int, dict]] = {}
    for f in sorted((paths.scoring_out(pass_) / "collected").glob("*/*.json")):
        out.setdefault(f.parent.name, {})[int(f.stem)] = json.loads(f.read_text())
    return out


def _verdicts(pass_: str) -> dict[tuple, dict]:
    f = paths.scoring_out(pass_) / "review" / "verdicts.jsonl"
    rows = [json.loads(l) for l in f.read_text().splitlines() if l.strip()] if f.exists() else []
    return {(r["part"], r["arm"], str(r["step"])): r for r in rows}


def _judged(pass_: str, part: str, arm: str, key: str, verdicts: dict) -> dict:
    d = paths.scoring_out(pass_) / "judged" / part / arm / key
    lenses = {f.stem: json.loads(f.read_text()) for f in sorted(d.glob("*.json"))} if d.is_dir() else {}
    ok = {n: j["score"] for n, j in lenses.items() if j.get("status") == "ok" and j.get("score") is not None}
    owner = verdicts.get((part, arm, key.lstrip("0") or key))
    if not lenses and owner is None:
        return {"score": None, "why": "not judged"}
    used = owner["score"] if owner else (statistics.median(ok.values()) if ok else None)
    out = {"score": scales.judged(used), "lenses": ok, "disputed": len(ok) >= 2 and max(ok.values()) - min(ok.values()) >= 2}
    if owner:
        out["owner"] = owner
    if used is None:
        out["why"] = "judge_failed"
    return out


def _measured(part: str, rec: dict, base: dict | None, sc: dict) -> dict:
    h, q = _v(rec["hidden"]), _v(rec["quality"])
    if part == "correctness":
        return {"score": h["passed"] / h["total"]} if h and h["total"] else {"score": None, "why": "no hidden results"}
    if part == "regressions":
        r = _v(rec["regressions"])
        return {"score": r["rate"]} if r and r["rate"] is not None else {"score": None, "why": "no earlier tests"}
    if part == "mutation":
        if q and q["mutation_state"] == "measured":
            return {"score": q["mutation_score"]}
        return {"score": None, "why": q["mutation_state"] if q else "no quality results"}
    if part == "mypy_lint":
        if q and q["mypy_errors"] is not None and q["ruff_findings"] is not None:
            return {"score": scales.deduction(q["mypy_errors"] + q["ruff_findings"], sc["lint_per_error"])}
        return {"score": None, "why": "mypy or ruff crashed"}
    if base is None:
        return {"score": None, "why": "no baseline for this step"}
    if part == "churn":
        a, b = _v(rec["churn"]), _v(base["churn"])
        return ({"score": scales.churn_score(a["lines"], b["lines"], sc["ratio_cap"])} if a and b
                else {"score": None, "why": "churn not measured"})
    if part == "time":
        def per_test(r):
            t, hh = _v(r["time"]), _v(r["hidden"])
            return t["seconds"] / hh["passed"] if t and hh and hh["passed"] else None
        s = scales.ratio_score(per_test(rec), per_test(base), sc["ratio_cap"])
        return {"score": s} if s is not None else {"score": None, "why": "time or passed tests missing"}
    raise ValueError(part)


def _choice(pass_: str, arm: str, sc: dict) -> dict:
    f = paths.scoring_out(pass_) / "decisions" / "ratings.json"
    if not f.exists():
        return {"score": None, "why": "not rated"}
    table = {"good": sc["rating_good"], "acceptable": sc["rating_acceptable"], "poor": sc["rating_poor"]}
    rs = [scales.rating(r["rating"], table) for t in json.loads(f.read_text())["topics"] for r in t["routes"]
          if arm in r["arms"]]
    rs = [r for r in rs if r is not None]
    return {"score": sum(rs) / len(rs)} if rs else {"score": None, "why": "no rated routes"}


def _part_steps(pass_, dim, part, arm, recs, base_recs, rubrics, verdicts, sc) -> dict[str, dict]:
    if part in ARM_LEVEL:
        if part == "choice":
            return {"arm": _choice(pass_, arm, sc)}
        if part == "violations":
            vs = [_v(r["violations"]) for r in recs.values()]
            vs = [v for v in vs if v is not None]
            return {"arm": {"score": scales.deduction(sum(len(v) for v in vs), sc["violation_per_item"])}
                    if vs else {"score": None, "why": "no run records"}}
        return {"arm": _judged(pass_, part, arm, "arm", verdicts)}
    if part in MEASURED:
        return {str(n): _measured(part, r, base_recs.get(n), sc) for n, r in sorted(recs.items())}
    steps = [n for n in rubrics[part].steps if n in recs]
    return {str(n): _judged(pass_, part, arm, f"{n:02d}", verdicts) for n in steps}


def _part_score(steps: dict) -> float | None:
    xs = [s["score"] for s in steps.values() if s["score"] is not None]
    return sum(xs) / len(xs) if xs else None


def _dimension(dim: str, parts: dict, w: inputs.Weights) -> dict:
    share = (lambda p: w.part_share(dim, p)) if dim in w.parts else (lambda p: 1.0)
    measured = {p: v["score"] for p, v in parts.items() if v["score"] is not None}
    score = (w.dimensions[dim] * sum(share(p) * s for p, s in measured.items()) / sum(share(p) for p in measured)
             if measured else None)
    return {"score": score, "max": w.dimensions[dim], "parts": parts,
            "unmeasured_parts": sorted(p for p in parts if parts[p]["score"] is None)}


def _guard(pass_: str, arms: list[str]) -> None:
    reviewed = inputs.load_excluded().reviewed
    pending = sorted({t for ts in evidence.all_fail(paths.RESULTS / pass_, arms).values() for t in ts} - reviewed)
    if pending:
        raise inputs.InputError("tests every arm failed are not reviewed in scoring/excluded-tests.toml: "
                                + ", ".join(pending))


def run(pass_: str, baseline: str = "control") -> Path:
    w, rubrics, verdicts = inputs.load_weights(), inputs.load_rubrics(), _verdicts(pass_)
    sc, coll = w.scales, _collected(pass_)
    _guard(pass_, sorted(coll))
    arms_out, flags = {}, []
    for arm in sorted(coll):
        dims = {}
        for dim in w.dimensions:
            names = list(w.parts.get(dim, {dim: 0}))
            parts = {}
            for part in names:
                steps = _part_steps(pass_, dim, part, arm, coll[arm], coll.get(baseline, {}), rubrics, verdicts, sc)
                parts[part] = {"score": _part_score(steps), "steps": steps}
            dims[dim] = _dimension(dim, parts, w)
            if dims[dim]["score"] is None:
                flags.append(f"{arm}: {dim} unmeasured")
            flags += [f"{arm}: {dim}.{p} unmeasured" for p in dims[dim]["unmeasured_parts"]]
        arms_out[arm] = {"total": sum(d["score"] for d in dims.values() if d["score"] is not None),
                         "dimensions": dims}
    out = paths.scoring_out(pass_) / "scores.json"
    out.parent.mkdir(parents=True, exist_ok=True)
    out.write_text(values.dump({"baseline": baseline, "weights": {"dimensions": w.dimensions, "parts": w.parts},
                                "arms": arms_out, "flags": sorted(flags)}))
    return out
```

```python
# runner/scoring/confidence.py
"""Spec §10: does the order change if weights move ±5, if disputed judgements go to their extreme lens, or both?"""
from __future__ import annotations


def _step_score(st: dict, mode: str) -> float | None:
    if mode != "median" and st.get("disputed") and "owner" not in st and st.get("lenses"):
        return (min if mode == "low" else max)(st["lenses"].values()) / 4
    return st.get("score")


def _part(part: dict, mode: str) -> float | None:
    xs = [s for s in (_step_score(st, mode) for st in part["steps"].values()) if s is not None]
    return sum(xs) / len(xs) if xs else None


def total(arm: dict, dims_w: dict, parts_w: dict, mode: str) -> float:
    t = 0.0
    for dim, d in arm["dimensions"].items():
        shares = parts_w.get(dim) or {p: 1.0 for p in d["parts"]}
        measured = {p: s for p, s in ((p, _part(v, mode)) for p, v in d["parts"].items()) if s is not None}
        if measured:
            t += dims_w[dim] * sum(shares[p] * s for p, s in measured.items()) / sum(shares[p] for p in measured)
    return t


def weight_variants(dims_w: dict) -> list[tuple[str, dict]]:
    out = [("base", dict(dims_w))]
    for dim in sorted(dims_w):
        for delta in (5, -5):
            new = max(0.0, dims_w[dim] + delta)
            rest = {k: v for k, v in dims_w.items() if k != dim}
            scale = (100 - new) / sum(rest.values())
            out.append((f"{dim} {delta:+d}", {**{k: v * scale for k, v in rest.items()}, dim: new}))
    return out


def check(scores: dict) -> dict:
    dims_w, parts_w, arms = scores["weights"]["dimensions"], scores["weights"]["parts"], scores["arms"]
    base = {a: total(v, dims_w, parts_w, "median") for a, v in arms.items()}
    ranking = sorted(arms, key=lambda a: (-base[a], a))
    intervals = {a: [base[a], base[a]] for a in arms}
    changes = []
    for name, w in weight_variants(dims_w):
        for mode in ("median", "low", "high"):
            t = {a: total(v, w, parts_w, mode) for a, v in arms.items()}
            for a in arms:
                intervals[a] = [min(intervals[a][0], t[a]), max(intervals[a][1], t[a])]
            order = sorted(arms, key=lambda a: (-t[a], a))
            if order != ranking:
                changes.append({"variant": f"{name}, judges {mode}", "order": order})
    groups: list[list[str]] = []
    for a in ranking:
        if groups and intervals[a][1] >= intervals[groups[-1][-1]][0]:
            groups[-1].append(a)
        else:
            groups.append([a])
    return {"ranking": ranking, "intervals": intervals, "groups": groups, "order_changes": changes}
```

```python
    xs = sorted(v for v in vals.values() if v)

    med = xs[len(xs) // 2] if len(xs) % 2 else (xs[len(xs) // 2 - 1] + xs[len(xs) // 2]) / 2
    return {a: ("high" if v >= factor * med else "low") for a, v in sorted(vals.items())
```

```python
from __future__ import annotations
import json

from runner.scoring import aggregate, collect, confidence, evidence, inputs, page, report, values


def _report(ns):
    out = paths.scoring_out(ns.pass_)
    (out / "confidence.json").write_text(values.dump(confidence.check(json.loads((out / "scores.json").read_text()))))
    report.run(ns.pass_)
    page.run(ns.pass_)


STAGES = {
    "all-fail": lambda ns: print(json.dumps(evidence.all_fail(paths.RESULTS / ns.pass_,
                                                               collect.arms(paths.RESULTS / ns.pass_)), indent=2)),
    "collect": lambda ns: print(len(collect.run(ns.pass_, docker=not ns.no_docker)), "records"),

DEFAULT = ("collect", "aggregate", "report")


def score(ns) -> int:

    return 0
```

```python
# runner/scoring/judge.py (pure parts)
"""Judged parts (spec §6): three lenses per part, anonymised inputs, one JSON verdict per call, written as it lands."""
from __future__ import annotations
import json, re
from dataclasses import asdict, dataclass, field
from pathlib import Path
from typing import Protocol
from runner import paths
from runner.scoring import inputs, values


class BadReply(ValueError):
    pass


@dataclass
class Verdict:
    score: int | None
    status: str
    evidence: list[str] = field(default_factory=list)
    notes: str = ""
    raw: str = ""


def parse(text: str) -> Verdict:
    m = re.search(r"\{.*\}", text, re.S)
    try:
        o = json.loads(m[0]) if m else None
    except json.JSONDecodeError as e:
        raise BadReply(f"not JSON: {e}") from e
    if not isinstance(o, dict) or type(o.get("score")) is not int or not 0 <= o["score"] <= 4:
        raise BadReply("needs an integer score 0-4")
    ev = o.get("evidence")
    if not isinstance(ev, list) or not ev or not all(isinstance(x, str) and x.strip() for x in ev):
        raise BadReply("needs at least one evidence citation (path, sha or transcript line)")
    return Verdict(o["score"], "ok", ev, str(o.get("notes", "")), text)


class Judge(Protocol):
    def ask(self, prompt: str, inputs: Path) -> str: ...


class FakeJudge:
    def __init__(self, replies: list[str]):
        self.replies, self.prompts = list(replies), []

    def ask(self, prompt: str, inputs: Path) -> str:
        self.prompts.append(prompt)
        return self.replies.pop(0)


def ask_with_retry(j: Judge, prompt: str, inputs_dir: Path) -> Verdict:
    reply = j.ask(prompt, inputs_dir)
    try:
        return parse(reply)
    except BadReply as e:
        reply = j.ask(f"{prompt}\n\nYour previous reply could not be used ({e}). Reply with one JSON object only.",
                      inputs_dir)
        try:
            return parse(reply)
        except BadReply:
            return Verdict(None, "judge_failed", raw=reply)


def out_path(pass_: str, part: str, arm: str, key: str, lens: str) -> Path:
    return paths.scoring_out(pass_) / "judged" / part / arm / key / f"{lens}.json"


def run(pass_: str, j: Judge) -> dict:
    rubrics, asked, skipped = inputs.load_rubrics(), 0, 0
    for part, arm, key, lens in items(pass_):
        out = out_path(pass_, part, arm, key, lens)
        if out.exists():
            skipped += 1
            continue
        d, files = inputs_for(pass_, part, arm, key)
        r = rubrics.get(part)
        lens_d = next((l for l in r.lenses if l["name"] == lens), {"name": lens, "perspective": ""}) if r else \
            {"name": lens, "perspective": ""}
        v = ask_with_retry(j, prompt(r, lens_d, key, files) if r else "", d)
        out.parent.mkdir(parents=True, exist_ok=True)
        out.write_text(values.dump(asdict(v)))
        asked += 1
    return {"asked": asked, "skipped": skipped}
```
